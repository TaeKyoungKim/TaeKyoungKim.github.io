COURSE SYLLABUS

머신러닝 개론

Introduction to Machine Learning · 한 학기(16주) · 이론 3학점 + 실습 병행

1. 강의 개요

이 강의는 머신러닝의 핵심 이론과 알고리즘을 체계적으로 다루는 이론 중심 과목이다. 지도학습과 비지도학습의 수학적 원리를 이해하고, 모델을 평가·검증하는 방법을 익히며, 신경망과 딥러닝의 기초까지 확장해 학습한다. 매 주차 이론 강의와 함께 Python(scikit-learn, Pandas, NumPy, TensorFlow/Keras)을 활용한 실습을 병행하여, 개념이 실제 데이터에서 어떻게 동작하는지 확인한다.

대상 학부 3~4학년 및 대학원생 (확률·통계, 선형대수 기초 수강 권장)
선수 지식 Python 기초 문법, 미적분학, 선형대수(벡터·행렬), 확률과 통계 개론
사용 도구 Python, Jupyter/Colab, NumPy, Pandas, scikit-learn, TensorFlow/Keras
교재 『Hands-On Machine Learning』(Aurélien Géron) · 『패턴 인식과 머신러닝』(Bishop, 참고) · 강의자료 슬라이드

2. 학습 목표

이 강의를 마치면 학생은 다음을 할 수 있다.

  • 지도학습·비지도학습 알고리즘의 수학적 원리를 설명하고 적절한 상황에 적용할 수 있다.
  • 모델의 성능을 올바른 지표와 검증 절차로 평가하고, 과적합·과소적합을 진단·해결할 수 있다.
  • 신경망의 순전파·역전파 원리를 이해하고, CNN·RNN 등 대표 딥러닝 구조를 설계할 수 있다.
  • 실제 데이터셋에 전처리부터 모델링, 평가까지 전체 파이프라인을 구현할 수 있다.

학습목표 — 머신러닝에 필요한 확률·통계 개념을 복습하고 연결한다.

4주차 · 선형회귀

  • 경사하강법(배치/확률적/미니배치)의 원리와 학습률

  • 시그모이드 함수와 결정경계
  • 교차엔트로피 손실함수와 최적화

학습목표 — 올바른 지표와 절차로 모델 성능을 평가하고 과적합을 제어할 수 있다.

  • 편향-분산 트레이드오프, 학습곡선 해석
  • K-겹 교차검증, 홀드아웃, 데이터 분할 전략

학습목표 — 거리 기반·마진 기반 분류기의 원리와 활용을 이해한다.

  • 커널 트릭(선형, RBF, 다항)과 비선형 분류

10주차 · 비지도학습: 군집화

학습목표 — 레이블 없는 데이터에서 군집 구조를 찾는 방법을 이해한다.

  • K-means 알고리즘과 초기값 민감도, 엘보우 기법
  • 계층적 군집화(응집형)와 덴드로그램 해석

  • 군집 품질 평가: 실루엣 계수, 관성(Inertia)

11주차 · 차원 축소

학습목표 — 고차원 데이터를 저차원으로 축소하는 원리와 활용을 이해한다.

  • 차원의 저주와 차원 축소의 필요성
  • 주성분분석(PCA)의 수학적 원리와 분산 설명력
  • 특이값분해(SVD)와 PCA의 관계
  • t-SNE를 이용한 고차원 데이터 시각화

12주차 · 신경망 기초와 역전파

학습목표 — 인공신경망의 구조와 학습 원리(역전파)를 이해한다.

  • 퍼셉트론에서 다층퍼셉트론(MLP)으로의 확장
  • 활성화 함수(시그모이드, ReLU, tanh)의 역할과 비교
  • 순전파와 역전파, 연쇄법칙(chain rule)
  • 경사하강법 변형: SGD, Momentum, Adam

실습 NumPy로 역전파 직접 구현, Keras Sequential 모델 · 참고 Géron 10장

13주차 · 딥러닝 심화

학습목표 — 신경망 학습을 안정화하고 일반화 성능을 높이는 기법을 익힌다.

  • 가중치 초기화(Xavier, He) 전략
  • 배치 정규화(Batch Normalization)의 원리
  • 드롭아웃과 조기 종료(Early Stopping)를 통한 과적합 방지
  • 학습률 스케줄링과 옵티마이저 비교

실습 Keras로 정규화·드롭아웃 적용 비교 실험 · 참고 Géron 11장

14주차 · CNN과 이미지 처리

학습목표 — 합성곱 신경망의 구조와 이미지 처리 원리를 이해한다.

  • 합성곱 연산(필터, 스트라이드, 패딩)의 원리
  • 풀링 계층(Max/Average Pooling)의 역할
  • 대표 아키텍처 개관: LeNet, VGG, ResNet
  • 전이학습(Transfer Learning)의 개념과 활용

실습 Keras CNN으로 이미지 분류(CIFAR-10/Fashion-MNIST) · 참고 Géron 14장

15주차 · RNN과 자연어처리 기초

학습목표 — 순차 데이터 처리 구조와 자연어처리의 기본 개념을 이해한다.

  • 순환신경망(RNN)의 구조와 기울기 소실 문제

  • 단어 임베딩(Word2Vec, GloVe)의 개념
  • Attention 메커니즘과 Transformer 구조 개관

실습 Keras LSTM으로 감성 분석(텍스트 분류) · 참고 Géron 15~16장

팀별 최종 프로젝트 결과를 발표하고, 한 학기 동안 다룬 알고리즘과 개념을 정리한다. 이후 심화 학습 방향(강화학습, 생성모델, MLOps 등)을 함께 소개한다.

6. 강의 운영 정책

  • 매 주차 실습 과제는 다음 주 수업 전까지 제출한다.
  • 결석 3회 이상 시 학점에 불이익이 있을 수 있다.
  • 팀 프로젝트는 3~4인으로 구성하며, 9주차에 주제를 확정한다.
  • 모든 코드 과제는 재현 가능성을 위해 노트북 파일과 함께 제출한다.
