통합 부록 — 원문 대응표·목차·일관성 점검·참고문헌

이 문서는 1단계 설계에서 계획한 4단계("통합")의 산출물이다. 2~9부를 모두 집필한 뒤, 원본 PDF(machine_learning_with_python.pdf)를 다시 직접 열어 각 절의 "원문 대비 달라진 점" 서술이 실제 원문과 정확히 일치하는지 재검증했다. 그 과정에서 중대한 오류 1건과 경미한 누락 2건을 발견해 각 절의 해당 부분을 정정했다 — 그 상세 내역을 이 문서 1절에 먼저 기록한다.

1. 통합 검토에서 발견한 오류와 정정 내역

1-1. [중대] 8부·9부의 "원문 Chapter 08/09" 서술은 사실이 아니었음

원본 PDF를 pdfplumber로 다시 페이지별 추출해 확인한 결과, 원문은 Chapter 01~07로 구성되어 있고 총 427쪽 중 마지막 페이지(427쪽)까지 Chapter 07(군집화, Mean Shift·GMM 부분)의 내용이 이어지며 그대로 끝난다. Chapter 08이나 09에 해당하는 내용은 원문에 전혀 존재하지 않는다.

  • 문제: 8부는 "원문(Chapter 08)은 대용량 데이터 처리 기법을 다룬다"고, 9부는 "원문(Chapter 09)은 모델 해석·설명가능성을 다룬다"고 서술했다. 둘 다 존재하지 않는 원문 내용을 사실처럼 기술한 것으로, 이 교재 전체가 지켜야 할 "원문을 임의로 창작하지 않는다"는 원칙을 어긴 것이다.
  • 원인 추정: 1단계 설계 단계에서 "9부작 구조"를 계획하면서, 8~9부가 원문 범위를 넘어서는 신규 추가 절이라는 점이 이후 집필 단계까지 명확히 전달되지 않아 "원문(Chapter N)" 표현을 기계적으로 재사용한 것으로 보인다.
  • 조치: 8부·9부 서두의 "원문 대비 달라진 점" 안내문을 "정정(통합 검토 중 발견)" 안내로 교체해, 두 절 모두 원문에 대응하는 장이 전혀 없는 신규 추가 절이라는 점과 그 근거(직접 페이지 재추출 결과)를 명시했다. 두 절이 실제로 다루는 기법과 실행 결과 자체는 정정 대상이 아니며(코드 재실행으로 이미 검증됨), 정정된 것은 오직 "이것이 원문의 어느 부분에 대응하는가"라는 출처 서술이다.

1-2. [경미] 7부가 원문 Chapter 07의 실제 구성을 부정확하게 서술

7부는 원래 "원문(Chapter 07)은 K-평균·계층적 군집화·실루엣 점수를 다루며 DBSCAN도 포함되어 있다"고 서술했다. 원문을 다시 확인한 결과, 원문 Chapter 07(376~427쪽)은 K-평균·실루엣 분석·Mean Shift(커널 밀도 추정 포함)·GMM(가우시안 혼합 모델)을 iris 데이터로 다루며, 계층적 군집화와 DBSCAN은 원문에 등장하지 않는다.

  • 조치: 7부의 안내문을 수정해 원문의 실제 구성(K-평균·실루엣·Mean Shift·GMM)을 정확히 반영했다. 7부가 자체적으로 추가한 계층적 군집화(7.5절)와 연습문제의 DBSCAN은 "원문에 없는 신규 추가 기법"으로 명시했고, 원문에 있었지만 이 절에서 다루지 않은 Mean Shift·GMM은 "생략됨"으로 정확히 표시했다.

1-3. [경미] 6부가 원문 Chapter 06의 LDA·SVD·NMF 내용을 누락 고지

원문 Chapter 06(331~375쪽)은 PCA뿐 아니라 LDA(선형판별분석)와 SVD·NMF(행렬 분해)도 함께 다루는데, 6부의 최초 안내문은 이 부분을 언급하지 않았다.

  • 조치: 6부 안내문에 원문이 LDA·SVD·NMF도 다룬다는 사실과, 이 절에서는 지면상 PCA만 다루고 나머지는 생략했다는 점을 명시했다. 또한 6부에 누락되어 있던 정확한 페이지 범위(331~375쪽)와 7부의 페이지 범위(376~427쪽)도 이번에 추가했다.

1-4. 사실로 확인되어 수정하지 않은 항목

아래 서술들은 이번 통합 검토에서 원문과 대조해 정확함을 확인했다(그대로 유지):

  • 2부: Chapter 02(68~122쪽)가 iris로 API를 소개한 뒤 타이타닉 생존자 예측을 다룬다는 서술 — 111~121쪽에서 "타이타닉 생존자 ML예측 구현" 직접 확인.
  • 3부: Chapter 03(123~159쪽)이 피마 인디언 당뇨병 데이터를 사용한다는 서술 — 151쪽에서 직접 확인.
  • 4부: Chapter 04(160~228쪽)가 결정트리·앙상블(보팅/배깅-랜덤포레스트/부스팅-AdaBoost·GBM)·SVM·kNN을 사용자행동인식·위스콘신 유방암·붓꽃 데이터로 다룬다는 서술 — 161~228쪽 전체 목차로 직접 확인.
  • 5부: Chapter 05(229~330쪽)가 RSS·경사하강법, 보스턴 집값, 다항회귀, 릿지/라쏘/엘라스틱넷, 데이터 변환, 로지스틱회귀, 회귀트리, 자전거 대여 수요를 다룬다는 서술 — 229~330쪽 전체 목차로 직접 확인.
  • 6부: Chapter 06의 신용카드 데이터 PCA 실습이 351~355쪽에 실제로 존재한다는 서술 — 페이지 내용(청구·상환 6개 피처 PCA)까지 직접 확인.

4. 절 간 표기 일관성 점검 결과

아래 항목을 8개 절 파일 전체에서 검색해 대조했다.

  • 랜덤시드: 모든 절이 RANDOM_STATE=42(또는 random_state=42)로 일관되게 사용함 — 불일치 없음.
  • 패키지 버전: 2~7·9부가 pandas 3.0.2/numpy 2.4.4/scikit-learn 1.8.0/matplotlib 3.10.9를 동일하게 명시함. 8부는 scikit-learn을 쓰지 않아 해당 항목을 생략하고 pyarrow/psutil/sqlite3만 추가로 명시했는데, 이는 실제 코드 의존성과 일치하므로 불일치가 아님. 9부는 shap 버전(0.51.0)을 인계 메모에 명시함 — 일관성 있음.
  • 데이터 라이선스 문구: 2부에서 "확인 완료 — CC BY 4.0" + 정식 인용을 명시한 이후, 3·6·7·9부가 "CC BY 4.0"을 짧게 재인용하는 방식으로 일관됨. 4·5·8부는 데이터 정의를 "2~N부와 동일"으로 참조만 하며 라이선스를 재기술하지 않는데, 이는 반복을 피하기 위한 것으로 문제가 되지 않는다(단, 5부는 애초에 실제 데이터가 아닌 합성 데이터라 라이선스 항목이 필요 없음).
  • 인계 메모 형식: 모든 절이 "완료한 범위 / 데이터·변수 정의 / 실행 환경 / 코드·이미지 검증 상태 / 남은 문제 / 다음 작업" 6개 항목을 동일한 순서로 포함함 — 형식 일관성 확인됨.
  • 12단계 절 구조: 모든 절(2~9부)이 "① 금융 상황과 질문 ② 학습목표 ③ 직관적 설명 ④ 용어와 수식 ⑤ 손 계산 예제 ⑥ 데이터 정의 ⑦ 코드 ⑧ 결과 해석 ⑨ 그림 ⑩ 흔한 오해 ⑪ 요약 ⑫ 연습문제(+해설)" 순서를 그대로 지킴 — 구조 일관성 확인됨(9부만 최종 프로젝트 안내를 위해 13·14절을 추가로 붙였으며, 이는 마무리 절의 특수성에 따른 의도된 확장임).

6. 남은 통합 작업(향후)

이번 통합 검토로 원문 대응표의 정확성 문제와 코드 완결성(10개 항목 중 "코드 완결성") 문제는 해결되었으나, 다음은 아직 다루지 않았다.

  1. [완료] 코드 완결성(print문 누락) 전수 점검 — 2~9부 전체: 모든 절의 코드 블록을 실제로 추출·독립 실행해 봤을 때, 코드에 print 문이 없어 본문이 주장하는 "실제 실행 결과" 수치를 재현할 수 없는 블록이 있는지 점검했다. 4부(5개 중 3개), 5부(5개 전부), 6부(5개 전부), 7부(4개 중 3개, 나머지 1개는 시각 전용이라 제외), 8부(4개 중 2개), 9부(5개 중 4개)에서 누락을 발견해 모두 수정했다. 이미 3단계 검수를 거쳤다고 표시되어 있던 2·3부도 다시 직접 점검한 결과, 3부의 7.4절(임계값 비교) 코드가 검증 비용(0.50 기준)과 테스트 세트 confusion matrix·비용(5,159→3,873)을 계산은 하면서도 출력하지 않는 누락이 있어 함께 수정했다(2부는 결과 출력이 없는 두 블록이 모두 파이프라인 설정 코드일 뿐이라 문제가 없음을 확인). 수정 후 2~9부 전 절의 코드 블록을 다시 추출·독립 실행하여 본문의 모든 수치와 정확히 일치함을 확인했다.
  2. 개별 절 검수(3단계, 10개 항목 판정): 2·3부에는 이미 적용했으나 4~9부에는 아직 적용하지 않았다. 동일한 10개 항목(원문/신규 구분, 초심자 난이도, 데이터 정의 일관성, 미래정보 누수, 분할 전략, 전처리·튜닝 누수, 코드 완결성, 계산-코드-그림 일치, 그림 제작방식 구분, 연습문제/해설/인계메모 일관성) 기준의 검수를 원하면 요청해 달라. (코드 완결성 항목은 위 0번에서 4~9부 전체에 대해 선제적으로 해결했으므로, 남은 검수는 나머지 9개 항목에 집중하면 된다.)
  3. 표지·저작권 안내 페이지: 이 교재가 원본 강의자료의 구조를 참고해 재구성한 파생 저작물임을 밝히는 공식 저작권/이용 안내 문구는 아직 작성하지 않았다.
  4. 전체 용어집(용어 사전): 각 절 4절("용어와 수식")에 흩어진 용어를 하나로 모은 부록 용어집은 아직 만들지 않았다.
