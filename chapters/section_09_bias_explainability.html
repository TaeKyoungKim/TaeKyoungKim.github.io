9부. 편향·설명가능성·최종 프로젝트

정정(통합 검토 중 발견): 이 절을 처음 작성할 때 "원문(Chapter 09)"이라는 표현을 사용했으나, 이는 사실이 아니다. 원본 PDF를 직접 재확인한 결과 원문은 Chapter 01~07(총 427쪽)로 끝나며, Chapter 09는 존재하지 않는다 — 8부와 마찬가지로 이 정정으로 이전 서술을 대체한다. 이 절은 원문에 대응하는 장이 전혀 없는, 이 교재가 새로 추가한 마무리 절이다. 신용평가 모델은 실제로 성별·연령 등에 따른 차별적 영향과 "왜 거절되었는가"에 대한 설명 의무가 법적·윤리적으로 중요하게 다뤄지는 영역이므로, 금융 특화 교재를 마무리하는 절로서 (1) 4부에서 고른 최종 모델(GBM)을 재사용한 성별·연령대별 예측 격차 공정성 분석과 (2) SHAP을 이용한 개별 고객 단위 설명을 전부 새로 설계해 담았다(1단계 설계에서 결정, 통합 검토 시 원문 대응 여부 재확인). 마지막으로 2~8부 전체를 종합하는 최종 프로젝트 안내로 이 교재를 마무리한다.

1. 금융 상황과 해결할 질문

지금까지(2~4부) 만든 신용위험 모델은 성능(AUC)만 보고 골랐다. 하지만 실제로 이런 모델을 서비스에 쓰려면 최소한 두 가지를 더 확인해야 한다. 첫째, 이 모델이 특정 집단(성별, 연령대)에 불리하게 작동하지는 않는가? 둘째, 한 고객이 "왜 내 신용카드 한도가 조정되었는지" 물었을 때, 모델의 판단 근거를 구체적으로 설명할 수 있는가? 성능이 좋은 모델이라도 이 두 질문에 답하지 못하면 실무에 배포하기 어렵다.

4부에서 고른 최종 모델(GBM)이 성별·연령대에 따라 다른 성능이나 승인율을 보이는가? 그리고 특정 고객 한 명에 대해, 이 모델이 왜 그런 예측을 했는지 구체적인 근거를 제시할 수 있는가?

2. 학습목표와 선수지식

  1. 승인율·오탐률(FPR)·미탐률(FNR) 같은 성능 지표를 집단별로 나누어 비교하고, 불평등 비율(disparate impact ratio)을 계산할 수 있다.
  2. 민감 변수(예: 성별)를 모델에서 제거해도 격차가 남을 수 있는 "프록시 변수" 문제를 이해한다.
  3. SHAP 값을 이용해 모델의 전역 중요도와 개별 예측의 근거를 모두 설명할 수 있다.

선수지식: 4부의 GBM·GridSearchCV, 2부의 혼동행렬·정밀도·재현율.

3. 직관적 설명

두 반의 시험 평균 점수가 같더라도, 한 반은 모든 학생이 고르게 잘 봤고 다른 반은 몇 명만 매우 잘 보고 나머지는 못 봤을 수 있다 — "전체 평균"만으로는 이 차이를 알 수 없다. 모델의 공정성 점검도 마찬가지다: 전체 AUC가 높아도, 그 안에서 특정 집단만 유난히 성능이 나쁘거나 승인율이 낮을 수 있다. 그리고 "이 모델이 왜 그렇게 판단했는가"를 설명하는 것은, 마치 요리사가 "이 요리가 왜 짠지" 설명할 때 "소금을 이만큼, 간장을 이만큼 넣어서"라고 재료별 기여도를 말해주는 것과 같다 — SHAP은 각 피처(재료)가 최종 예측(맛)에 얼마나, 어느 방향으로 기여했는지를 숫자로 알려준다.

4. 용어와 수식

불평등 비율(Disparate Impact Ratio): 두 집단의 승인율(또는 다른 긍정 판정 비율) 중 작은 값을 큰 값으로 나눈 비율.

$$\text{DI ratio} = \frac{\min(\text{승인율}_A, \text{승인율}_B)}{\max(\text{승인율}_A, \text{승인율}_B)}$$

미국 고용평등위원회(EEOC)의 "4/5 규칙"에서는 이 비율이 0.8 미만이면 차별적 영향의 소지가 있다고 보는 경험적 기준을 사용한다(법적 판단의 유일한 기준은 아니며, 참고 지표로 이해해야 한다).

FPR(False Positive Rate, 오탐률)·FNR(False Negative Rate, 미탐률): 2부에서 배운 혼동행렬을 집단별로 나누어 계산한 것. FPR은 "실제로는 정상인데 연체로 잘못 예측한 비율", FNR은 "실제로는 연체인데 정상으로 잘못 예측한 비율"이다.

프록시 변수(Proxy Variable): 민감 변수(성별 등)를 모델에서 직접 제거해도, 그 변수와 상관된 다른 변수(예: 특정 소비 패턴)가 사실상 같은 역할을 해서 격차가 그대로 남는 현상.

SHAP(SHapley Additive exPlanations): 게임이론의 섀플리 값(Shapley value)을 이용해, 하나의 예측값을 "각 피처가 기준값(평균 예측)에서 얼마나 더하거나 뺐는가"로 정확히 분해하는 방법. 모든 피처의 SHAP 값을 더하면 정확히 그 예측값이 된다는 수학적 성질이 있다.

5. 손으로 확인하는 작은 숫자 예제

그룹 A 100명 중 80명이 승인(예측)되고, 그룹 B 100명 중 60명이 승인되었다고 하자.

$$\text{승인율}_A = \frac{80}{100} = 0.80, \qquad \text{승인율}_B = \frac{60}{100} = 0.60$$

$$\text{DI ratio} = \frac{\min(0.80, 0.60)}{\max(0.80, 0.60)} = \frac{0.60}{0.80} = 0.75$$

0.75는 0.8 미만이므로, 이 예제는 "4/5 규칙" 기준으로 차별적 영향의 소지가 있다고 판단할 수 있는 상황이다(코드로 확인, 7.2절). 이 간단한 계산이 7.3절에서 실제 모델의 성별·연령대별 승인율에 그대로 적용된다.

6. 데이터 정의와 분석 설계

데이터와 모델: 2~4부와 동일한 UCI 신용카드 실제 데이터, 그리고 4부 GridSearchCV가 고른 최종 GBM(n_estimators=200, max_depth=2)을 동일한 학습/테스트 분할로 재현해 사용한다. 재현한 모델의 테스트 AUC(0.7763)가 4부에서 보고한 값과 정확히 일치하는지부터 확인한다.

공정성 점검 기준 변수: 데이터에 이미 포함된 SEX(1=남성, 2=여성)와 AGE를 4개 구간(21-30, 31-40, 41-50, 51+)으로 나눈 값을 기준으로, 실제 연체율·예측 승인율·FPR·FNR·AUC를 집단별로 비교한다. 주의: SEX는 4부 모델의 입력 변수로 이미 포함되어 있었다 — 이 절에서는 그 사실을 숨기지 않고 그대로 드러내어 점검한다.

검증 규칙: 공정성 점검과 SHAP 설명 모두 테스트 세트에서만 수행한다 — 학습 세트에서 확인하면 모델이 학습 과정에서 이미 본 데이터의 특성을 그대로 반영할 뿐이라, 새로운 고객에게 일반화되는 격차인지 알 수 없기 때문이다(3부 이후 지켜온 원칙과 동일).

7.1 4부 최종 GBM 재현

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import roc_auc_score, confusion_matrix

RANDOM_STATE = 42
raw = pd.read_csv("UCI_Credit_Card.csv")
df = raw.drop(columns=["ID"]).rename(
    columns={"PAY_0": "PAY_1", "default.payment.next.month": "default"}
)
df["EDUCATION"] = df["EDUCATION"].replace({0: 4, 5: 4, 6: 4})
df["MARRIAGE"] = df["MARRIAGE"].replace({0: 3})

X = df.drop(columns=["default"]); y = df["default"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=RANDOM_STATE
)

numeric_features = ["LIMIT_BAL", "AGE", "PAY_1", "PAY_2", "PAY_3", "PAY_4", "PAY_5", "PAY_6",
    "BILL_AMT1", "BILL_AMT2", "BILL_AMT3", "BILL_AMT4", "BILL_AMT5", "BILL_AMT6",
    "PAY_AMT1", "PAY_AMT2", "PAY_AMT3", "PAY_AMT4", "PAY_AMT5", "PAY_AMT6"]
categorical_features = ["SEX", "EDUCATION", "MARRIAGE"]

def make_preprocess():
    return ColumnTransformer([("num", StandardScaler(), numeric_features),
                               ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features)])

gbm_pipe = Pipeline([("preprocess", make_preprocess()),
                      ("model", GradientBoostingClassifier(n_estimators=200, max_depth=2, random_state=RANDOM_STATE))])
gbm_pipe.fit(X_train, y_train)
test_proba = gbm_pipe.predict_proba(X_test)[:, 1]
test_pred = (test_proba >= 0.5).astype(int)
test_auc = roc_auc_score(y_test, test_proba)

print(f"테스트 AUC = {test_auc:.4f}")

실제 실행 결과: 재현한 테스트 AUC = 0.7763으로, 4부에서 보고한 GBM 테스트 AUC(0.7763)와 정확히 일치한다.

7.2 성별·연령대별 성능·승인율 점검

X_test_eval = X_test.copy()
X_test_eval["y_true"] = y_test.values
X_test_eval["y_proba"] = test_proba
X_test_eval["y_pred"] = test_pred
X_test_eval["approved"] = (X_test_eval["y_pred"] == 0).astype(int)  # 예측이 '연체 아님'이면 승인

def group_metrics(sub):
    tn, fp, fn, tp = confusion_matrix(sub["y_true"], sub["y_pred"], labels=[0, 1]).ravel()
    return pd.Series({
        "n": len(sub), "실제_연체율": sub["y_true"].mean(), "승인율": sub["approved"].mean(),
        "FPR": fp / (fp + tn), "FNR": fn / (fn + tp),
        "AUC": roc_auc_score(sub["y_true"], sub["y_proba"]),
    })

by_sex = X_test_eval.groupby("SEX").apply(group_metrics, include_groups=False).round(4)

X_test_eval["AGE_BIN"] = pd.cut(X_test_eval["AGE"], bins=[20, 30, 40, 50, 80],
                                  labels=["21-30", "31-40", "41-50", "51+"], right=True)
by_age = X_test_eval.groupby("AGE_BIN", observed=True).apply(group_metrics, include_groups=False).round(4)

print("[성별]\n", by_sex)
print("불평등 비율(성별) =", round(by_sex["승인율"].min() / by_sex["승인율"].max(), 4))
print("[연령대]\n", by_age)
print("불평등 비율(연령대) =", round(by_age["승인율"].min() / by_age["승인율"].max(), 4))

실제 실행 결과(성별):

SEX n 실제 연체율 승인율(예측) FPR FNR AUC
남성(1) 2,402 0.2336 0.8730 0.0587 0.6488 0.7746
여성(2) 3,598 0.2129 0.8852 0.0477 0.6371 0.7766

불평등 비율 = $0.8730/0.8852 = 0.9862$ — 0.8을 훨씬 웃돌아 4/5 규칙 기준으로는 문제 소지가 크지 않다. FPR·FNR도 두 집단 간 차이가 1~1.2%p 수준으로 크지 않다.

7.3 SEX 변수를 제거해도 격차가 남는지 확인 (프록시 변수 점검)

categorical_features_noSex = ["EDUCATION", "MARRIAGE"]

def make_preprocess_nosex():

                               ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features_noSex)])

gbm_nosex = Pipeline([("preprocess", make_preprocess_nosex()),

gbm_nosex.fit(X_train.drop(columns=["SEX"]), y_train)
proba_nosex = gbm_nosex.predict_proba(X_test.drop(columns=["SEX"]))[:, 1]
pred_nosex = (proba_nosex >= 0.5).astype(int)
auc_nosex = roc_auc_score(y_test, proba_nosex)

X_test_eval["approved_nosex"] = (pred_nosex == 0).astype(int)

print(f"SEX 제거 후 테스트 AUC = {auc_nosex:.4f} (원래 {test_auc:.4f})")
print("SEX별 예측 승인율(SEX 제거 모델):\n", approval_by_sex_nosex.round(4))

실제 실행 결과: SEX를 제거해도 테스트 AUC는 0.7764로 원래(0.7763)와 사실상 동일하고, 성별 그룹별 예측 승인율도 남성 0.8747/여성 0.8835(불평등 비율 0.9900)로 SEX를 포함했을 때(0.9862)와 거의 같다. 즉 이 데이터에서는 SEX를 모델에서 빼도 성능도 격차도 거의 바뀌지 않는다 — SEX 자체가 예측에 크게 기여하지 않았고, 다른 변수를 통한 뚜렷한 프록시 효과도 관찰되지 않았다는 뜻이다(8절에서 이 결과가 "격차가 전혀 없다"는 뜻은 아니라는 점을 다시 설명한다).

7.4 SHAP으로 전역 피처 중요도 확인

import shap

preprocess_fitted = gbm_pipe.named_steps["preprocess"]
model_fitted = gbm_pipe.named_steps["model"]
X_test_transformed = preprocess_fitted.transform(X_test)
feature_names = preprocess_fitted.get_feature_names_out()
X_test_transformed_df = pd.DataFrame(X_test_transformed, columns=feature_names, index=X_test.index)

explainer = shap.TreeExplainer(model_fitted)
shap_values = explainer(X_test_transformed_df)

import numpy as np
mean_abs_shap = pd.Series(np.abs(shap_values.values).mean(axis=0), index=feature_names).sort_values(ascending=False)
builtin_importance = pd.Series(model_fitted.feature_importances_, index=feature_names).sort_values(ascending=False)

print("[SHAP 상위 5]\n", mean_abs_shap.head(5).round(4))
print("[feature_importances_ 상위 5]\n", builtin_importance.head(5).round(4))
print("상위 10개 중 겹치는 피처 수 =",
      len(set(mean_abs_shap.head(10).index) & set(builtin_importance.head(10).index)))

실제 실행 결과: SHAP 기준 상위 피처는 PAY_1(0.4456), LIMIT_BAL(0.1927), BILL_AMT1(0.1088), PAY_AMT1(0.1051), PAY_AMT2(0.0994) 순이다(그림 9-2). 4부의 feature_importances_ 기준 상위 피처(PAY_1 0.6501, PAY_2 0.0588, PAY_3 0.0469, BILL_AMT1 0.0301, PAY_5 0.0281)와 비교하면, 두 방식 모두 상위 10개 중 8개가 겹친다 — PAY_1이 가장 중요하다는 결론은 일치하지만, 두 번째로 중요한 변수(SHAP은 LIMIT_BAL, 기본 중요도는 PAY_2)는 다르게 나온다. 이는 두 지표가 "중요도"를 계산하는 방식이 다르기 때문이다(8절에서 설명).

7.5 개별 고객 2명에 대한 SHAP 설명

high_risk_idx = int(np.argmax(test_proba))
low_risk_idx = int(np.argmin(test_proba))

for idx, label in [(high_risk_idx, "고위험"), (low_risk_idx, "저위험")]:
    sv = shap_values[idx]
    order = np.argsort(np.abs(sv.values))[::-1][:8]
    top_features = pd.Series(sv.values[order], index=[feature_names[i] for i in order])
    print(f"[{label} 고객] 예측확률={test_proba[idx]:.3f}, 실제={'연체' if y_test.iloc[idx]==1 else '정상'}")
    print(top_features.round(2))

실제 실행 결과: 예측확률이 가장 높은 고위험 고객(예측확률 0.912, 실제로도 연체)의 경우 PAY_1(+1.79)이 위험을 가장 크게 높였고, BILL_AMT1(+1.13)·BILL_AMT2(+0.50)가 뒤를 이었으며 LIMIT_BAL(-0.14)·AGE(-0.06)만 위험을 소폭 낮추는 방향이었다. 반대로 예측확률이 가장 낮은 저위험 고객(예측확률 0.026, 실제로도 정상)은 BILL_AMT1(-0.41)·PAY_AMT2(-0.35)·PAY_AMT1(-0.26)·PAY_1(-0.25)·LIMIT_BAL(-0.19) 등 거의 모든 상위 피처가 위험을 낮추는 방향으로 작용했다(그림 9-3). 이런 개별 설명은 "이 고객은 왜 이런 예측을 받았는가"라는 질문에 구체적인 근거(어떤 변수가, 얼마나, 어느 방향으로)를 제시할 수 있게 해준다.

8. 결과 읽는 법과 업무상 의미

이번 데이터·모델에서는 뚜렷한 공정성 문제가 발견되지 않았다: 성별(0.9862)·연령대(0.9593) 불평등 비율 모두 0.8을 크게 웃돌았고, SEX를 제거해도 결과가 거의 바뀌지 않았다. 하지만 이것이 "이 모델은 항상 공정하다"는 뜻은 아니다 — 이 결과는 이 데이터셋, 이 모델, 이 임계값(0.5)에서만 확인된 것이며, 다른 임계값이나 다른 민감 변수(예: 지역, 소득 추정치)를 기준으로 하면 다른 결론이 나올 수 있다. 공정성 점검은 "한 번 통과하면 끝"이 아니라 모델을 운영하는 내내 반복해야 하는 과정이다.

SHAP과 기본 feature_importances_가 다른 이유: GBM의 기본 feature_importances_는 트리를 만들 때 "그 변수로 분기했을 때 불순도가 얼마나 줄었는가"를 트리 전체에서 합산한 값이다. 반면 SHAP은 게임이론에 기반해 "각 피처가 평균 예측값에서 이 예측값까지 얼마나 기여했는가"를 개별 예측 단위로 계산한 뒤 평균낸 값이다. 두 방식이 상위 1위(PAY_1)에는 동의하지만 세부 순위가 다른 것은, 두 지표가 "중요도"를 정의하는 방식 자체가 다르기 때문이지 어느 한쪽이 틀렸기 때문이 아니다.

개별 설명의 실무적 가치: 7.5절의 두 사례처럼, SHAP은 "이 고객은 최근 연체(PAY_1)와 높은 청구액(BILL_AMT1) 때문에 위험도가 높게 나왔다"처럼 사람이 이해할 수 있는 설명을 만들어준다. 이는 금융권에서 실제로 요구되는 "불리한 결정에 대한 설명 의무"(고객이 왜 거절되었는지 알 권리)에 대응하는 데 핵심적인 도구다. 다만 SHAP은 "이 모델이 그렇게 계산했다"는 것을 설명할 뿐, "그 계산이 실제 인과관계를 반영한다"는 것을 보장하지는 않는다(6부에서 다룬 다중공선성처럼, 상관된 변수 사이에서는 기여도 배분이 달라질 수 있다).

10. 흔한 오해와 오류

  • 오해 1: "불평등 비율이 0.8을 넘으면 이 모델은 완전히 공정하다." 0.8이라는 기준은 하나의 경험적 참고선일 뿐, 법적·윤리적 공정성을 보장하는 절대 기준이 아니다. 또한 이 절은 승인율(demographic parity 관점) 하나만 확인했다 — FPR·FNR 격차(equalized odds 관점) 등 다른 공정성 정의로는 다른 결론이 나올 수 있다(연습문제 5).
  • 오해 2: "SHAP 중요도가 높은 변수가 곧 그 변수의 실제 인과적 효과 크기다." 6부에서 다중공선성을 다룰 때 확인했듯, 상관된 변수들 사이에서는 "기여도를 어떻게 나눌 것인가"에 따라 SHAP 값도 달라질 수 있다. SHAP은 "이 모델의 계산 과정"을 설명하는 것이지, 데이터 뒤의 실제 인과관계를 증명하는 것이 아니다.
  • 오류 1: "민감 변수를 모델에서 빼면 그것으로 공정성 문제는 해결된다." 7.3절에서 이 데이터는 SEX를 빼도 격차가 거의 바뀌지 않았지만, 일반적으로는 그렇지 않을 수 있다. 다른 변수가 민감 변수의 정보를 간접적으로 담고 있으면(프록시), 민감 변수를 빼도 격차가 그대로 남거나 오히려 눈에 덜 띄는 형태로 숨어버릴 수 있다 — 반드시 "뺀 후에도 격차를 다시 측정"해서 확인해야 한다.
  • 오류 2: "임계값 0.5로 계산한 승인율 격차가 유일한 공정성 지표다." 3부에서 배운 것처럼 임계값은 비용 구조에 따라 달라질 수 있다. 임계값을 바꾸면 집단별 승인율과 FPR·FNR도 함께 달라지므로, 공정성 점검도 하나의 임계값에서 끝내지 말고 여러 임계값에서 반복해야 한다.

11. 핵심 요약

모델의 성능이 좋다는 것과 공정하다는 것은 별개의 질문이다. 이 절에서는 4부 최종 GBM 모델을 재사용해 성별·연령대별 승인율·FPR·FNR을 비교했고, 이번 데이터·모델에서는 두 기준 모두 4/5 규칙(불평등 비율 0.8)을 크게 웃돌았으며 SEX를 제거해도 결과가 거의 바뀌지 않았다. 하지만 이는 이 특정 사례에 대한 결론일 뿐, 공정성 점검을 생략해도 된다는 뜻은 아니다. SHAP은 게임이론에 기반해 전역 중요도와 개별 예측 근거를 모두 설명할 수 있게 해주며, GBM의 기본 feature_importances_와는 계산 방식이 다르지만 핵심 결론(가장 중요한 변수는 PAY_1)은 일치했다.

12. 연습문제

개념 문제
1. 승인율 기준 불평등 비율(demographic parity)과 FPR·FNR 기준 공정성(equalized odds)이 서로 다른 결론을 낼 수 있는 이유를 설명하라.
2. SHAP 값과 GBM의 기본 feature_importances_가 "중요도"를 다르게 정의하는 방식을 설명하라.

계산 문제
3. 그룹 A 200명 중 150명이 승인, 그룹 B 150명 중 90명이 승인되었을 때 불평등 비율을 계산하고 4/5 규칙을 통과하는지 판단하라.
4. 어떤 고객의 SHAP 값이 PAY_1: +0.8, LIMIT_BAL: -0.3, BILL_AMT1: +0.2이고 기준값(평균 예측, 로그오즈 단위)이 -1.0일 때, 이 고객의 최종 예측값(로그오즈 합)을 계산하라.

실습 문제
5. 승인 임계값을 0.5 대신 3부에서 찾은 비용 최적 임계값(0.24)으로 바꿔 성별·연령대별 승인율 격차가 어떻게 달라지는지 확인하라.
6. EDUCATION(교육 수준)을 기준으로도 같은 공정성 점검(승인율, FPR, FNR)을 수행하고, 6절에서 확인한 EDUCATION=4(기타) 그룹의 표본 수가 적다는 한계가 이 분석에도 영향을 주는지 논하라.

연습문제 해설(별도)

  1. Demographic parity(승인율 동등성)는 "각 그룹이 얼마나 승인받는가"만 보고, 실제 정답이 무엇인지는 고려하지 않는다. Equalized odds(FPR·FNR 동등성)는 "실제 정답 대비 오류율이 그룹마다 같은가"를 본다. 두 그룹의 실제 연체율(기저율) 자체가 다르면, 승인율은 같게 만들면서 오류율은 다르게 나오거나 그 반대인 상황이 수학적으로 가능하다 — 두 기준을 동시에 완벽히 만족시키기 어려운 경우가 실제로 존재한다.
  2. feature_importances_는 트리 구축 과정에서 그 변수로 분기했을 때 불순도가 감소한 정도를 전체 트리에 걸쳐 합산한 값으로, 모델 구조에 의존하는 전역적 지표다. SHAP은 개별 예측 하나하나에 대해 "그 변수가 없었다면 예측이 얼마나 달라졌을까"를 게임이론적으로 공정하게 배분한 값을 모든 예측에 대해 평균 낸 것으로, 개별 설명과 전역 설명을 같은 논리로 연결한다는 차이가 있다.
  3. 승인율: $150/200=0.75$, $90/150=0.60$. 불평등 비율 $=0.60/0.75=0.80$. 정확히 0.8이므로 4/5 규칙의 경계선에 있다(통상 "0.8 미만"을 문제로 보므로, 이 경우는 아슬아슬하게 기준을 통과한다).
  4. 최종 로그오즈 $= -1.0 + 0.8 - 0.3 + 0.2 = -0.3$. (SHAP 값의 정의상 모든 피처의 SHAP 값을 기준값에 더하면 정확히 최종 예측값이 된다.)
  5. (실습형) 임계값을 0.24로 낮추면 전체 승인율이 낮아지고(더 많은 고객이 "연체 위험"으로 분류됨), 실제 연체율이 더 높은 집단(이 절의 51+ 연령대 등)에서 승인율이 상대적으로 더 크게 떨어져 불평등 비율이 0.5 임계값일 때보다 낮아질(격차가 커질) 가능성이 있다 — 임계값 선택이 공정성에도 영향을 준다는 것을 확인하는 것이 목적이다.
  6. (실습형) 2부에서 이미 확인했듯 EDUCATION=4(기타)는 표본이 상대적으로 적어(연습문제 실행 시 확인), 이 그룹의 승인율·FPR·FNR 추정치가 다른 그룹보다 불안정(표본 변동에 민감)할 수 있다 — 표본이 적은 그룹에 대한 공정성 결론은 더 신중하게 해석해야 한다는 점을 확인하는 것이 목적이다.

13. 최종 프로젝트 안내

이 교재(2~9부)는 신용카드 연체 예측(분류), 성능 평가와 비용 기반 임계값 선택, 트리·앙상블 모델 비교, 회귀(고객 지출액 예측), 차원 축소(PCA), 군집화(고객 세분화), 대용량 데이터 처리, 공정성·설명가능성까지 실제 금융 데이터 분석의 전체 파이프라인을 다뤘다. 최종 프로젝트는 이 전체 흐름을 학습자가 스스로 한 번 더 수행해보는 것을 목표로 한다.

프로젝트 과제(제안): 이 교재에서 다루지 않은 새로운 각도로 credit_default 데이터(또는 라이선스가 명확한 다른 금융 공개 데이터)를 분석하라. 예를 들어:

  1. 결측치·이상치가 있는 원본 데이터로 재도전: 이 교재는 EDUCATION·MARRIAGE의 정의되지 않은 코드만 병합했다. BILL_AMT가 음수인 경우, LIMIT_BAL이 극단적으로 큰 경우 등을 직접 탐색하고 처리 방식을 정당화하라.
  2. 다른 목적변수로 재구성: "다음 달 연체 여부" 대신 "6개월 내 연체 여부"나 "연체 심각도(연체 개월 수)"처럼 새로운 목적변수를 정의하고, 왜 그 정의가 타당한지 설명하라.
  3. 전체 파이프라인 재현: 데이터 로드 → 탐색적 분석 → 학습/테스트 분할(누수 없이) → 최소 2개 이상 모델 비교(GridSearchCV로 하이퍼파라미터 탐색) → 비용 기반 임계값 선택(3부 방식) → 최종 모델의 공정성 점검(9부 방식) → SHAP으로 개별 설명 최소 2건.
  4. 핸드오프 메모 작성: 이 교재의 각 절처럼, 데이터 정의·검증 상태·남은 한계를 명시한 메모를 프로젝트 결과물에 포함하라.

평가 기준(제안): (a) 데이터 누수 없이 학습/테스트를 분리했는가, (b) 기준모델(베이스라인) 대비 개선을 실제로 확인했는가, (c) 그림과 표의 수치가 실제 코드 실행 결과와 일치하는가, (d) 결과 해석에서 과장된 주장을 하지 않았는가(예: 상관관계를 인과관계로 서술하지 않았는가), (e) 모델의 한계와 잠재적 공정성 문제를 스스로 점검했는가.

14. 핵심 요약(교재 전체)

이 교재는 UCI 신용카드 연체 데이터를 중심축으로, 분류(2~4부)·회귀(5부, 합성 데이터)·비지도 학습(6~7부)·인프라(8부)·책임 있는 AI(9부)까지 실제 금융 빅데이터 분석에 필요한 전체 기술 스택을 실제로 실행 가능한 코드와 함께 다뤘다. 모든 절에서 일관되게 지킨 원칙은 데이터 누수 방지(전처리·튜닝·임계값 선택은 학습 세트 내부에서만), 실제 실행 결과만 보고(코드로 만든 숫자만 본문에 기재), 실측·합성 데이터의 명확한 구분이다. 이 세 원칙은 이 교재의 특정 예제를 넘어, 실무에서 어떤 금융 데이터 분석을 하든 반드시 지켜야 할 기본기다.

  • 완료한 범위: 9부("편향·설명가능성·최종 프로젝트") 전체를 12단계 구조 + 최종 프로젝트 안내(13절)로 집필하고, 실행·시각 검증까지 완료. 이로써 1단계 설계에서 계획한 2~9부 전체 집필이 완료되었다.
  • 이번 범위의 변수·모델 정의: 2~4부와 동일한 credit_default(UCI, 실제 데이터, CC BY 4.0), 4부 GridSearchCV가 고른 최종 GBM(n_estimators=200, max_depth=2)을 동일한 학습/테스트 분할로 재현. 공정성 점검 기준은 SEX(1/2)와 AGE를 4구간으로 나눈 값, 승인 임계값은 4부와 동일한 기본값 0.5.
  • 사용 환경과 데이터: Python 3.11+/pandas 3.0.2/numpy 2.4.4/scikit-learn 1.8.0/matplotlib 3.10.9 + shap 0.51.0. 전체 스크립트 실행 시간 약 31초.
  • 코드·이미지 검증 상태: 스크립트 전체 실행 완료(에러 없음). 재현한 GBM 테스트 AUC(0.7763)가 4부 보고값과 정확히 일치. 손 계산 예제(불평등 비율 0.75)가 코드 실행 결과와 정확히 일치. 성별·연령대별 성능표, SEX 제거 전후 비교, SHAP 전역·개별 중요도 수치가 모두 본문과 일치. 그림 3종 모두 실제 생성·육안 확인 완료.
  • 남은 문제: (1) 이 절의 공정성 점검은 승인율(demographic parity) 중심이며, equalized odds 등 다른 공정성 정의로 재점검하는 것은 연습문제로만 제시 (2) 51+ 연령대(표본 471명)처럼 표본이 작은 그룹의 지표는 불안정할 수 있다는 한계를 본문에 명시했으나 신뢰구간 등 통계적 검정은 이 교재 범위를 넘어 다루지 않음 (3) SHAP은 TreeExplainer(GBM 전용, 계산이 빠름)만 사용했고, 모델에 무관하게 쓸 수 있는 KernelExplainer 등은 다루지 않음.
  • [통합 검토 중 발견·수정]: 7.1~7.4의 코드 블록 4개에 print 문이 없어(7.5만 있었음), 본문의 "실제 실행 결과"(테스트 AUC, 성별·연령대별 표, SEX 제거 후 AUC·승인율, SHAP·기본 중요도 상위 5개)를 코드만 추출해 실행해서는 확인할 수 없는 상태였다. 4개 블록 모두에 결과를 출력하는 print 문을 추가했고, 5개 코드 블록 전체를 다시 추출해 독립 스크립트로 실행한 결과 테스트 AUC(0.7763), 성별·연령대별 승인율·불평등 비율(0.9862/0.9593), SEX 제거 후 AUC(0.7764)·승인율(0.9900), SHAP·feature_importances_ 상위 5개 값과 상위 10개 중 겹치는 피처 수(8개), 개별 고객 2명의 SHAP 값이 모두 본문과 정확히 일치함을 확인했다.
