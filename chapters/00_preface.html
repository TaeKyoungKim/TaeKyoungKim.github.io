들어가며 — 파이썬으로 배우는 금융 빅데이터 분석

이 교재의 목적

이 교재는 최용(2021)의 강의자료 「Python으로 시작하는 빅데이터분석 및 인공지능」(PowerPoint 기반 PDF, 총 427쪽, Chapter 01~07)의 학습 구조를 바탕으로, 그 내용을 금융 데이터 분석이라는 하나의 축으로 재구성한 교재다. 원문은 붓꽃(iris)·타이타닉·위스콘신 유방암·보스턴 집값·자전거 대여 수요 등 여러 도메인의 예제를 통해 머신러닝 전반(분류·평가·트리·앙상블·회귀·차원 축소·군집화)을 다루지만, 이 교재는 그 이론적 뼈대는 최대한 그대로 유지하면서 거의 모든 실습 사례를 신용카드 연체 예측이라는 하나의 금융 문제로 통일했다. 같은 데이터를 절이 바뀔 때마다 다른 각도(분류 → 평가 → 앙상블 → 차원 축소 → 군집화 → 설명가능성)에서 반복해서 들여다보면, 매번 새로운 데이터셋을 익히는 데 드는 노력 없이 "분석 기법 자체의 차이"에 집중할 수 있다는 것이 이 재구성의 핵심 의도다.

대상 독자와 선수지식

파이썬 기초 문법과 pandas·numpy의 기본적인 사용 경험이 있고, 통계학의 평균·분산·상관계수 정도의 개념에 익숙한 학습자를 대상으로 한다. 머신러닝을 처음 접하더라도 각 절이 "직관적 설명 → 용어와 수식 → 손으로 푸는 작은 예제 → 실제 코드"의 순서로 단계를 밟아가므로 따라올 수 있도록 구성했다. 원문 Chapter 01("파이썬 기반의 머신러닝 생태계 이해")은 머신러닝 일반론과 개발 환경 소개로, 금융 데이터로 재구성할 특정 실습이 없어 별도의 절로 다시 쓰지 않았다 — 이 서문이 그 역할(교재의 목적, 범위, 환경)을 대신한다.

이 교재가 다루는 범위 (2~11부)

부 제목 핵심 기법 원문 대응
2부 첫 분류 모델 로지스틱회귀, 결정트리, 기준모델 비교 Chapter 02 일부 + Chapter 04 초반
3부 분류 모델 평가와 임계값 선택 혼동행렬, 정밀도·재현율·F1·ROC-AUC, 비용 기반 임계값 Chapter 03
4부 트리와 앙상블 기반 신용위험 모델 비교 결정트리, 랜덤포레스트, GBM, GridSearchCV Chapter 04
5부 회귀 — 고객 월별 카드 지출액 예측 RSS, 경사하강법, 릿지·라쏘, 다중공선성 Chapter 05
6부 차원 축소 — 청구·상환 변수의 PCA 공분산행렬, 고유값/고유벡터, PCA Chapter 06(PCA 부분)
7부 군집화 — 고객 세분화 K-평균, 엘보우, 실루엣 점수 Chapter 07(K-평균 부분)
8부 대용량 데이터 처리 — 청크·SQL·Parquet 청크 단위 처리, SQLite, Parquet 원문에 없음(신규 추가)
9부 편향·설명가능성·최종 프로젝트 공정성 지표, SHAP, 최종 프로젝트 원문에 없음(신규 추가)
10부 딥러닝 — 다층 퍼셉트론(MLP)으로 신용위험 예측 순전파·역전파, 활성화함수, 과대적합(에폭), 신경망 vs 트리 앙상블 원문에 없음(신규 추가)
11부 XAI 심화 — 모델에 무관한 설명 기법으로 신경망 들여다보기 순열 중요도, 부분의존도(PDP), 국소 근사(LIME 방식) 원문에 없음(신규 추가)

중요한 정정 사항 (통합 검토 중 발견): 8부와 9부를 처음 작성할 때 "원문 Chapter 08", "원문 Chapter 09"라는 표현을 사용한 적이 있으나, 이는 사실이 아니었다. 원본 PDF를 다시 직접 확인한 결과 원문은 Chapter 01~07로 구성되어 있고 Chapter 07(군집화)이 427쪽에서 그대로 끝나며, Chapter 08·09는 존재하지 않는다. 8~11부 네 절 모두 정정 안내(또는 처음부터 명확한 신규 추가 표시)를 절 서두에 추가했고, 이 표에도 "원문에 없음(신규 추가)"으로 정확히 표시했다. 대용량 데이터 처리, 공정성·설명가능성, 딥러닝, XAI 심화는 "금융 빅데이터 분석"이라는 이 교재의 제목이 다루겠다고 약속한 범위이므로, 원문에 없더라도 이 교재가 새로 설계해 채운 절이다 — 이 사실을 숨기지 않고 명시하는 것이 이 교재 전체가 지켜온 "원문과 신규 내용을 구분한다"는 원칙에 부합한다. 10부의 환경 선택: 실무 딥러닝은 보통 TensorFlow·PyTorch를 쓰지만, 이 교재는 2~9부와 동일한 실행 환경을 유지하기 위해 scikit-learn의 MLPClassifier를 사용했다(10부 서두 참고). 11부의 LIME 관련 안내: 공식 lime 패키지가 이 실행 환경의 최신 빌드 도구와 호환되지 않아 설치할 수 없었으므로, 같은 원리(perturbation 기반 국소 선형 근사)를 11부가 직접 구현했다(11부 서두·인계 메모 참고).

데이터에 대한 안내

이 교재는 두 가지 데이터를 사용하며, 절마다 어떤 데이터를 쓰는지 첫머리에 명시한다.

  • 실제 데이터: UCI Machine Learning Repository의 "Default of Credit Card Clients"(대만, 2005년, 계좌 30,000개). 라이선스는 CC BY 4.0(Creative Commons Attribution 4.0 International)이며, 인용은 다음과 같다: Yeh, I. (2009). Default of Credit Card Clients [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C55S3H. 2·3·4·6·7·8·9·10·11부가 이 데이터(또는 이를 그대로 복제해 규모만 키운 버전, 8부)를 사용한다.
  • 교육용 합성 데이터: 5부("고객 월별 카드 지출액 예측")는 자유롭게 재현 가능한 실제 카드 지출액 데이터를 구하지 못해, 이 교재가 직접 생성한 합성 데이터를 사용한다. 5부 본문에 생성 코드와 함께 "실제 소비자 행동에 대한 근거로 사용해서는 안 된다"는 제한을 명시했다.

표기 규칙

  • 모든 코드는 RANDOM_STATE=42로 재현성을 고정했다.
  • 각 절의 "실제 실행 결과"는 실제로 코드를 실행해 얻은 값이며, 코드 없이 결과만 서술한 곳은 없다(통합 검토에서 두 군데의 누락을 발견해 수정했다 — 9부 인계 메모 참고).
  • 각 절은 "학습/검증/테스트 세트를 나눈다면 전처리·하이퍼파라미터·임계값 선택은 반드시 학습 세트 내부에서만 한다"는 데이터 누수 방지 원칙을 예외 없이 지킨다.
  • 각 절 끝의 "인계 메모"는 그 절의 완료 범위, 검증 상태, 남은 한계를 다음 작업자(또는 다음 절을 쓰는 스스로)에게 전달하기 위한 것이다.

실행 환경

Python 3.11 이상, pandas 3.0.2, numpy 2.4.4, scikit-learn 1.8.0, matplotlib 3.10.9를 기본으로 하고, 8부는 pyarrow·psutil·표준 라이브러리 sqlite3를, 9부는 shap을 추가로 사용한다. 10부·11부는 신규 패키지 설치 없이 scikit-learn 표준 기능(MLPClassifier, sklearn.inspection)만으로 신경망 학습과 모델-무관 설명을 구현했다. 모든 버전은 이 교재를 실제로 집필·실행한 환경에서 확인한 값이다.
