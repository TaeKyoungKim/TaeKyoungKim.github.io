7부. 군집화 — 고객 세분화

이 절에서 원문 대비 달라진 점: 원문(Chapter 07, 376~427쪽)은 군집화 이론과 함께 K-평균·실루엣 분석·Mean Shift(커널 밀도 추정 포함)·GMM(가우시안 혼합 모델)을 iris 데이터로 실습한다(PDF에서 직접 확인 — DBSCAN과 계층적 군집화는 원문에 포함되어 있지 않다). 이 절은 원문의 K-평균·실루엣 분석 논리 구조는 그대로 유지하되, 사례는 2·4·6부에서 이미 사용한 credit_default(UCI, 실제 데이터) 고객들을 "이용 패턴이 비슷한 유형"으로 나누는 고객 세분화로 재구성했다. 계층적 군집화(7.5절)는 원문에 없는 신규 추가 비교 기법이며, 원문의 Mean Shift·GMM은 이 절에서 다루지 않고 통합 단계의 원문 대응표에 누락으로 명시한다(1단계 설계에서 확정, 통합 검토 시 재확인). DBSCAN도 원문에는 없지만 밀도 기반 군집화의 대표 사례로서 연습문제 6에 신규로 추가했다.

1. 금융 상황과 해결할 질문

카드사의 마케팅팀은 30,000명 전체 고객에게 똑같은 메시지를 보내는 대신, "한도는 낮지만 이용률이 높고 연체 이력이 있는 고객", "한도가 높고 안정적으로 소액만 쓰는 고객"처럼 비슷한 성향의 고객을 묶어 서로 다른 제안(한도 상향, 리볼빙 주의 안내, 프리미엄 카드 추천 등)을 할 수 있다면 더 효과적이다. 지금까지(2~6부)는 "정답(연체 여부)이 있는" 지도학습을 다뤘지만, 이번에는 정답 없이 데이터 안의 자연스러운 그룹을 찾아야 한다.

청구·상환 이력만 보고, 정답(연체 여부) 없이 고객을 몇 개의 유형으로 나눌 수 있는가? 그리고 그렇게 나눈 유형이 실제로 의미 있는 차이(예: 연체율)를 보이는가?

2. 학습목표와 선수지식

  1. K-평균 알고리즘이 "중심에 가장 가까운 점을 배정 → 중심을 다시 계산"을 반복해 군집을 찾는 과정을 손으로 계산할 수 있다.
  2. 엘보우 방법과 실루엣 점수를 이용해 군집 개수(k)를 근거 있게 선택할 수 있다.
  3. 군집화가 목적변수(레이블)를 쓰지 않는 비지도 학습임에도, 표준화는 여전히 학습 세트에만 fit해야 하는 이유를 설명할 수 있다.

선수지식: 2부의 StandardScaler, 6부의 PCA(시각화에 재사용).

3. 직관적 설명

친구들과 함께 사진을 찍고 "비슷하게 생긴 사람끼리 모여보라"고 하면, 누가 정답을 알려주지 않아도 사람들은 자연스럽게 몇 개의 무리로 나뉜다. K-평균은 이와 비슷하다 — 먼저 아무 곳에나 "무리의 중심" k개를 놓고, 각 사람(데이터)을 가장 가까운 중심에 배정한 뒤, 그 무리의 평균 위치로 중심을 다시 옮긴다. 이 "배정 → 중심 이동"을 중심이 더 이상 움직이지 않을 때까지 반복한다. 지도학습과 다른 점은, 애초에 "정답 무리"가 없다는 것이다 — 알고리즘이 데이터가 놓인 모양만 보고 스스로 무리를 나눈다.

4. 용어와 수식

K-평균(K-means) 알고리즘: $k$개의 중심 $\mu_1, ..., \mu_k$를 두고 다음을 반복한다.

  1. 배정 단계: 각 점 $x_i$를 가장 가까운 중심에 배정: $c_i = \arg\min_j |x_i - \mu_j|^2$
  2. 갱신 단계: 각 군집의 중심을 그 군집에 속한 점들의 평균으로 갱신: $\mu_j = \frac{1}{|C_j|}\sum_{i \in C_j} x_i$

더 이상 배정이 바뀌지 않으면(수렴하면) 멈춘다.

군집 내 제곱합(Inertia, WCSS): 각 점과 자신이 속한 군집 중심 사이 거리 제곱의 합. $k$가 커질수록 항상 감소한다.

$$\text{Inertia} = \sum_{j=1}^{k} \sum_{i \in C_j} |x_i - \mu_j|^2$$

엘보우 방법: $k$를 늘려가며 Inertia를 그렸을 때, 감소폭이 급격히 완만해지는("팔꿈치"처럼 꺾이는) 지점을 후보 $k$로 본다.

실루엣 점수(Silhouette Score): 각 점에 대해 "같은 군집 내 다른 점들과의 평균 거리($a$)"와 "가장 가까운 다른 군집과의 평균 거리($b$)"를 비교한다.

$$s_i = \frac{b_i - a_i}{\max(a_i, b_i)}, \qquad -1 \le s_i \le 1$$

$s_i$가 1에 가까울수록 자기 군집에 잘 속해 있고 다른 군집과는 잘 구분된다는 뜻이다. 전체 평균 실루엣 점수가 가장 높은 $k$를 정량적 기준으로 삼는다.

5. 손으로 확인하는 작은 숫자 예제

$x=[1, 2, 3, 9, 10]$이라는 1차원 데이터를 $k=2$로 군집화해보자. 초기 중심을 $\mu_1=2.0,\ \mu_2=9.0$으로 놓는다(임의 선택).

0단계(배정): 각 점을 더 가까운 중심에 배정한다. $1, 2, 3$은 $\mu_1=2.0$에 더 가깝고, $9, 10$은 $\mu_2=9.0$에 더 가깝다 → 군집1=${1,2,3}$, 군집2=${9,10}$.

1단계(갱신): 각 군집의 평균으로 중심을 다시 계산한다. $\mu_1 = (1+2+3)/3 = 2.0$(변화 없음), $\mu_2 = (9+10)/2 = 9.5$.

재배정: 새 중심 $\mu_1=2.0, \mu_2=9.5$로 다시 배정해도 ${1,2,3}$과 ${9,10}$의 소속은 바뀌지 않는다 — 배정이 더 이상 바뀌지 않으므로 1번의 갱신만으로 수렴했다(그림 7-1). 실제 데이터는 6차원(6절)이라 손으로 계산할 수 없지만, "가까운 것끼리 묶고 평균으로 중심을 옮기는" 원리는 동일하다.

6. 데이터 정의와 분석 설계

데이터: 2~4·6부와 동일한 UCI 신용카드 연체 데이터(credit_default, 실제 데이터, CC BY 4.0). 이번 절에서는 원본 변수 대신 세분화에 적합하도록 다음 6개 피처를 설계했다.

  • LIMIT_BAL(신용한도), AGE(나이): 원본 변수 그대로.
  • AVG_BILL_AMT = BILL_AMT1~6의 평균(최근 6개월 평균 청구액).
  • AVG_PAY_AMT = PAY_AMT1~6의 평균(최근 6개월 평균 상환액).
  • UTILIZATION = AVG_BILL_AMT / LIMIT_BAL(이용률, 0 이상 3 이하로 클립 — 일부 계좌는 청구액이 음수이거나 한도 대비 매우 크게 나올 수 있어 극단값을 제한).
  • PAY_1(가장 최근 달의 연체 개월 수, 4부에서 가장 중요했던 변수).

목적변수는 쓰지 않는다: 군집화는 default(연체 여부)를 전혀 보지 않고 위 6개 피처만으로 진행한다. default는 군집이 완성된 뒤 "이 군집이 실제로 의미 있는 차이를 보이는가"를 사후에 확인하는 용도로만 사용한다 — 군집화 자체에 레이블을 사용하면 그것은 더 이상 비지도 학습이 아니다.

검증 규칙: 표준화(StandardScaler)는 목적변수를 쓰지 않아도 입력 변수의 분산 구조를 학습하는 전처리이므로, 2·6부와 동일하게 학습 세트에만 fit한다. 군집 개수(k)는 학습 세트만으로 엘보우·실루엣 점수를 계산해 선택하고, 테스트 세트는 "학습 세트로 정한 군집 중심에 새 고객을 배정했을 때도 비슷하게 잘 나뉘는가"를 확인하는 데만 사용한다(predict로 배정, 재학습하지 않음) — 이는 3~4부에서 지킨 "테스트 세트는 최종 확인에만 사용" 원칙을 비지도 학습에도 동일하게 적용한 것이다.

7. 단계별 실습 코드와 설명

실행 환경: 2~6부와 동일(Python 3.11+/pandas 3.0.2/numpy 2.4.4/scikit-learn 1.8.0/scipy/matplotlib 3.10.9, random_state=42). 전체 실행 시간 약 14초.

7.1 데이터 로드와 세분화 피처 설계

import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split

RANDOM_STATE = 42

raw = pd.read_csv("UCI_Credit_Card.csv")
df = raw.drop(columns=["ID"]).rename(
    columns={"PAY_0": "PAY_1", "default.payment.next.month": "default"}
)
df["EDUCATION"] = df["EDUCATION"].replace({0: 4, 5: 4, 6: 4})
df["MARRIAGE"] = df["MARRIAGE"].replace({0: 3})

bill_cols = [f"BILL_AMT{i}" for i in range(1, 7)]
pay_amt_cols = [f"PAY_AMT{i}" for i in range(1, 7)]
df["AVG_BILL_AMT"] = df[bill_cols].mean(axis=1)
df["AVG_PAY_AMT"] = df[pay_amt_cols].mean(axis=1)
df["UTILIZATION"] = (df["AVG_BILL_AMT"].clip(lower=0) / df["LIMIT_BAL"]).clip(upper=3.0)

seg_cols = ["LIMIT_BAL", "AGE", "AVG_BILL_AMT", "AVG_PAY_AMT", "UTILIZATION", "PAY_1"]

df_train, df_test = train_test_split(
    df, test_size=0.2, random_state=RANDOM_STATE, stratify=df["default"]
)

7.2 표준화 + 엘보우 방법·실루엣 점수로 k 선택 (학습 세트만 사용)

from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(df_train[seg_cols])
X_test_scaled = scaler.transform(df_test[seg_cols])

sil_sample_idx = np.random.RandomState(RANDOM_STATE).choice(len(X_train_scaled), size=5000, replace=False)
inertias, silhouettes = [], []
for k in range(2, 9):
    km = KMeans(n_clusters=k, random_state=RANDOM_STATE, n_init=10)
    labels_k = km.fit_predict(X_train_scaled)
    inertias.append(km.inertia_)
    silhouettes.append(silhouette_score(X_train_scaled[sil_sample_idx], labels_k[sil_sample_idx]))

for k, i, s in zip(range(2, 9), inertias, silhouettes):
    print(f"k={k}: inertia={i:.1f}, silhouette={s:.4f}")

참고: 실루엣 점수는 전체 24,000개 학습 표본에 대해 계산하면 계산량이 많아지므로(모든 점 쌍 사이 거리 계산 필요), 무작위 5,000개 표본으로 근사했다. 이는 계산 효율을 위한 표준적인 관행이며, k 선택 결론 자체를 바꾸지 않는다(연습문제 5에서 표본 크기에 따른 안정성을 직접 확인해볼 수 있다).

실제 실행 결과: Inertia는 k=2의 111,448에서 k=8의 55,494까지 k가 커질수록 계속 감소한다(엘보우 곡선은 k=3~4 부근에서 완만해지기 시작). 실루엣 점수는 k=2: 0.2520, k=3: 0.2618(최고), k=4: 0.2435, k=5: 0.2564, k=6: 0.2281, k=7: 0.2335, k=8: 0.2385로, k=3에서 가장 높다(그림 7-2).

7.3 k=3으로 최종 군집화, 테스트 세트에 배정

FINAL_K = 3  # 실루엣 점수가 가장 높은 k를 그대로 채택
kmeans_final = KMeans(n_clusters=FINAL_K, random_state=RANDOM_STATE, n_init=10)
train_labels = kmeans_final.fit_predict(X_train_scaled)
test_labels = kmeans_final.predict(X_test_scaled)   # 테스트는 배정만, 재학습 없음

sil_train = silhouette_score(X_train_scaled[sil_sample_idx], train_labels[sil_sample_idx])
sil_test_idx = np.random.RandomState(RANDOM_STATE).choice(len(X_test_scaled), size=min(3000, len(X_test_scaled)), replace=False)
sil_test = silhouette_score(X_test_scaled[sil_test_idx], test_labels[sil_test_idx])
print(f"학습 세트 실루엣={sil_train:.4f}, 테스트 세트 실루엣={sil_test:.4f}")

실제 실행 결과: 학습 세트 실루엣 점수 0.2618, 테스트 세트(새로 배정) 실루엣 점수 0.2535로 큰 차이가 없다 — 학습 세트로 찾은 군집 구조가 새로운 고객에게도 비슷하게 적용된다는 뜻이다.

cluster_profile = df_train.groupby("cluster")[seg_cols + ["default"]].mean().round(2)
cluster_profile["n_customers"] = df_train.groupby("cluster").size()

실제 실행 결과: 40명 표본의 덴드로그램(그림 7-5)에서 최상위 수준(Ward 거리 약 13.3)에서 먼저 왼쪽의 소수 그룹(4명)이 나머지와 분리되고, 그 다음 수준(약 9.6)에서 나머지가 다시 두 그룹으로 갈라진다 — K-평균이 찾은 "3개 군집" 구조와 대략적으로 일치하는 계층 구조를 보인다. 계층적 군집화는 K-평균과 달리 미리 k를 정하지 않고 이런 트리 구조를 먼저 만든 뒤, 원하는 높이에서 잘라 군집 개수를 정할 수 있다는 차이가 있다.

8. 결과 읽는 법과 업무상 의미

군집화가 실제로 의미 있는 이유: 이번 군집화는 default(정답)를 전혀 보지 않았다는 점이 중요하다. 그럼에도 연체율이 가장 낮은 군집(15%)과 가장 높은 군집(31%)이 거의 2배 차이가 나고, 이 차이가 학습 세트와 테스트 세트에서 일관되게 나타난다. 이는 "이용률이 높고 최근 연체 이력이 있다"는 이용 패턴 자체가 미래 위험과 자연스럽게 연결된다는 뜻이며, 마케팅팀이 군집 0에는 리볼빙 주의 안내를, 군집 1·2에는 한도 상향이나 프리미엄 상품을 제안하는 식으로 활용할 수 있다.

실루엣 점수의 절대적 크기 해석: 이번 실루엣 점수(약 0.26)는 "매우 뚜렷하게 갈라진 군집"(보통 0.5 이상)이라 보기는 어렵다. PCA 산점도(그림 7-4)에서도 군집 사이 경계가 뚜렷한 벽이라기보다는 점진적으로 섞이는 형태다. 이는 실제 금융 데이터에서 흔한 현상이다 — 고객의 이용 패턴은 몇 개의 뚜렷한 유형으로 딱 떨어지기보다 연속적인 스펙트럼에 가까운 경우가 많다. 그럼에도 군집 간 연체율 차이가 실무적으로 유의미하므로, "완벽하게 분리된 군집"이 아니어도 세분화 자체는 유용할 수 있다.

엘보우와 실루엣이 다른 k를 가리킬 수 있다: 엘보우 곡선만 보면 k=3~5 어디를 골라도 그럴듯해 보이지만, 실루엣 점수는 k=3에서 뚜렷한 최고점을 보인다. 두 기준이 일치하지 않을 때는 정량적 기준(실루엣)과 실무적 해석 가능성(너무 많은 군집은 활용하기 어려움)을 함께 고려해 최종 선택을 내려야 한다 — 이번에는 둘 다 3을 지지했다.

10. 흔한 오해와 오류

  • 오해 1: "군집 개수(k)는 원하는 만큼 늘려도 된다, 세분화가 세밀할수록 좋다." Inertia는 k를 늘릴수록 항상 감소하므로 이것만으로는 k를 정할 수 없다(극단적으로 k=고객 수면 Inertia=0이지만 아무 의미가 없다). 실루엣 점수처럼 "군집 간 분리 정도"를 함께 보는 지표가 필요하다.
  • 오해 2: "군집화 결과에서 연체율 차이가 크게 나왔으니, 이 군집 번호 자체를 연체 예측 모델의 입력으로 써도 된다." 가능은 하지만, 군집 번호 하나로 뭉뚱그리면 4부의 PAY_1 같은 개별 변수가 가진 세밀한 정보를 잃는다. 군집은 "고객을 이해하고 그룹별 전략을 세우는" 목적에 적합하며, 정밀한 개별 예측에는 2~4부의 지도학습 모델이 더 적합하다.
  • 오류 1: "군집화는 레이블을 안 쓰니까 학습/테스트를 나눌 필요가 없다." 6절에서 설명했듯, 군집화도 입력 변수의 분산 구조(표준화)와 군집 중심을 "학습"하는 과정이다. 새로운 고객에게도 일관되게 적용할 계획이라면, 지도학습과 마찬가지로 학습 세트로 구조를 정하고 테스트 세트로 일반화 여부(이번 절의 실루엣 점수 0.2618→0.2535)를 확인하는 것이 안전하다.
  • 오류 2: "모든 피처를 표준화 없이 그대로 넣어도 된다." LIMIT_BAL(수만~수십만 원)과 PAY_1(-2~8 사이 정수)처럼 단위가 크게 다른 변수를 표준화 없이 넣으면, 값의 절대 크기가 큰 LIMIT_BAL이 거리 계산을 사실상 지배해 다른 변수의 정보가 묻힌다(6부의 PCA와 같은 이유).

11. 핵심 요약

K-평균은 "가장 가까운 중심에 배정 → 군집 평균으로 중심 갱신"을 반복해 데이터를 k개의 군집으로 나눈다. 군집 개수는 Inertia(엘보우 방법)와 실루엣 점수를 함께 보고 정하며, 이번 사례에서는 실루엣 점수가 가장 높은 k=3을 채택했다. 군집화는 목적변수를 쓰지 않는 비지도 학습이지만, 표준화와 군집 중심 학습은 여전히 학습 세트에만 fit해야 하며, 테스트 세트로 그 구조가 새 데이터에도 일반화되는지 확인할 수 있다. 실제로 레이블 없이 나눈 3개 군집이 연체율 15%~31%라는 뚜렷하고 재현 가능한 차이를 보였다.

12. 연습문제

개념 문제
1. 엘보우 방법만으로는 k를 정하기 어려운 이유를 Inertia의 성질을 이용해 설명하라.
2. 군집화 결과(군집 번호)를 연체 예측 모델의 입력 변수로 그대로 쓰는 것과, PAY_1 같은 원본 변수를 쓰는 것의 차이를 설명하라.

계산 문제
3. $x=[2, 4, 6, 20, 22]$를 $k=2$, 초기 중심 $\mu_1=4, \mu_2=20$으로 K-평균 1단계(배정과 중심 갱신)를 계산하라.
4. 어떤 점의 같은 군집 내 평균 거리 $a=2.0$, 가장 가까운 다른 군집까지의 평균 거리 $b=5.0$일 때 이 점의 실루엣 점수를 계산하라.

실습 문제
5. 실루엣 점수 계산에 쓰는 표본 크기를 5,000에서 10,000, 20,000(전체)으로 늘려가며 k=3의 실루엣 점수가 얼마나 안정적인지 확인하라.
6. DBSCAN(밀도 기반 군집화)을 같은 6개 피처에 적용해보고, K-평균과 달리 이상치를 "군집 없음(-1)"으로 자동 분류하는 결과를 K-평균 결과와 비교하라.

연습문제 해설(별도)

  1. Inertia는 군집 내 거리 제곱합이므로 군집을 잘게 나눌수록(k가 커질수록) 항상 감소하거나 같다 — 극단적으로 각 점이 자신만의 군집이면 Inertia=0이 되지만 이는 아무 정보도 요약하지 못한 것이다. 따라서 "Inertia가 작을수록 좋다"는 기준만으로는 항상 가장 큰 k를 고르게 되어 무의미하다.
  2. 군집 번호는 6개 변수를 하나의 범주(0/1/2)로 압축한 것이므로, "이 고객이 구체적으로 왜 위험한가"에 대한 세밀한 정보(예: 정확히 몇 개월 연체했는지)를 잃는다. 반면 PAY_1 같은 원본 변수는 그 세밀한 정보를 그대로 유지하므로, 정밀한 예측에는 원본 변수가, 그룹 단위의 전략 수립에는 군집 번호가 더 적합하다.
  3. $\mu_1=4$가 $2,4,6$에 더 가깝고 $\mu_2=20$이 $20,22$에 더 가깝다 → 군집1=${2,4,6}$, 군집2=${20,22}$. 갱신된 중심: $\mu_1=(2+4+6)/3=4.0$(변화 없음), $\mu_2=(20+22)/2=21.0$.
  4. $s = (b-a)/\max(a,b) = (5.0-2.0)/5.0 = 0.6$.
  5. (실습형) 표본 크기를 늘릴수록 실루엣 점수는 점점 더 안정적인(분산이 작은) 값에 수렴할 가능성이 높으며, 5,000개로 근사한 이 절의 값(0.2618)과 크게 다르지 않을 것으로 예상된다.
  6. (실습형) DBSCAN은 밀도가 낮은 지역의 점(예: 매우 극단적인 이용 패턴을 가진 소수 고객)을 "군집 없음"으로 분류할 수 있어, K-평균이 억지로 어느 한 군집에 포함시켰던 이상치를 별도로 식별할 수 있다는 차이를 관찰하는 것이 목적이다.
