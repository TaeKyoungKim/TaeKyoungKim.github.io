10부. 딥러닝 — 다층 퍼셉트론(MLP)으로 신용위험 예측

이 절에서 원문 대비 달라진 점: 원본 PDF(최용, 2021, 「Python으로 시작하는 빅데이터분석 및 인공지능」)를 직접 재확인한 결과, 원문은 Chapter 01~07(1~427쪽)로만 구성되어 있고 딥러닝·신경망을 다루는 장은 존재하지 않는다. 이 절은 8부·9부와 마찬가지로 원문에 대응하는 장이 전혀 없는, 이 교재가 새로 설계해 채운 절이다. "금융 빅데이터 분석"이라는 이 교재의 제목이 다루겠다고 약속한 범위(대용량 데이터 처리, 신경망, 설명가능성)를 채우기 위한 것이며, 이 사실을 숨기지 않고 명시하는 것이 이 교재 전체가 지켜온 "원문과 신규 내용을 구분한다"는 원칙에 부합한다. 환경 선택에 대한 안내: 실무의 딥러닝은 보통 TensorFlow나 PyTorch 같은 전용 프레임워크로 수행하지만, 이 절은 2~9부와 동일한 실행 환경(Python/pandas/numpy/scikit-learn/matplotlib)을 유지하기 위해 scikit-learn의 MLPClassifier(다층 퍼셉트론)를 사용한다. MLPClassifier는 은닉층·활성화함수·역전파를 갖춘 진짜 신경망이지만, 이미지·순차데이터에 쓰이는 합성곱·순환·어텐션 구조는 다루지 않는다 — 이 절이 "신경망의 기본 동작 원리"를 다루는 절이지 "최신 딥러닝 아키텍처 총람"이 아니라는 점을 8절에서 다시 짚는다.

1. 금융 상황과 해결할 질문

4부에서는 결정트리·랜덤포레스트·GBM을 비교해, GBM(AUC 0.7763)이 가장 나은 순위 성능을 보였다는 것을 확인했다. 신용위험 관리팀의 한 팀원이 "요즘 다들 딥러닝을 쓰던데, 신경망을 쓰면 이 트리 계열 모델들보다 더 잘 맞지 않겠느냐"고 묻는다. 이 질문에 답하려면 신경망이 정확히 무엇을 계산하는지, 이 데이터에 신경망을 어떻게 적용해야 하는지, 그리고 트리 계열과 비교했을 때 실제로 더 나은지를 직접 확인해야 한다.

신경망(다층 퍼셉트론)은 내부적으로 무엇을 계산하는가? 이 데이터에 신경망을 적용하려면 트리 모델과 무엇을 다르게 준비해야 하는가? 그리고 "층을 더 쌓고 뉴런을 늘리면 무조건 더 좋아진다"는 생각은 사실인가?

2. 학습목표와 선수지식

이 절을 마치면 다음을 할 수 있어야 한다.

  1. 다층 퍼셉트론의 순전파(가중합 → 활성화함수)와 역전파(경사하강법으로 가중치 갱신)를 작은 숫자 예제로 손으로 계산할 수 있다.
  2. 신경망이 트리 모델과 달리 입력 스케일에 민감한 이유를 설명하고, 실제로 표준화 유무에 따른 성능 차이를 데이터로 확인할 수 있다.
  3. 은닉층 구조·정규화 강도(alpha)를 교차검증으로 고르고, 에폭(반복 횟수)을 늘렸을 때 나타나는 과대적합을 진단할 수 있다.
  4. 신경망과 4부의 트리·앙상블 모델을 같은 지표(AUC, F1)로 공정하게 비교하고, 어느 쪽이 언제 유리한지 판단할 수 있다.

선수지식: 5부의 경사하강법·손실함수, 4부의 GridSearchCV·과적합 진단, 2부의 시그모이드 함수. 신경망을 처음 접해도 되도록 4절에서 순전파·역전파의 계산 과정을 단계별로 풀어 쓴다.

3. 직관적 설명

결정트리는 "PAY_1이 2 이상인가?"처럼 사람이 읽을 수 있는 규칙을 순서대로 적용해 판단한다. 신경망은 전혀 다른 방식으로 판단한다 — 모든 입력 변수에 각기 다른 "가중치"를 곱해 더한 뒤, 그 합을 비선형 함수(활성화함수)에 통과시켜 "새로운 특징"을 여러 개 만들어내고, 이 과정을 층층이 반복한다. 마지막 층에서는 이렇게 여러 번 변환된 값들을 다시 조합해 최종 확률을 낸다. 사람이 "이 계좌는 PAY_1이 크고 청구액도 크니까 위험하다"처럼 규칙으로 설명하기보다, 데이터 자체가 "어떤 조합이 위험 신호인지"를 수많은 가중치 숫자로 표현하는 방식이다. 이 절에서 사용하는 신경망은 입력층(23개 원본 피처를 전처리하면 29차원) → 은닉층 2개(32개, 16개 뉴런) → 출력층(1개 뉴런, 확률) 구조를 갖는다(그림 10-1).

이 방식의 장점은 사람이 미리 규칙을 정해주지 않아도 되는 유연함이지만, 단점도 명확하다 — 가중치가 수백~수천 개에 달해 "왜 이 확률이 나왔는지"를 사람이 직접 읽기 어렵다(이 문제는 11부에서 XAI 기법으로 다룬다). 또한 가중합을 계산하는 특성상 입력 변수들의 "크기"가 들쭉날쭉하면 학습이 잘 되지 않는다 — 트리는 "PAY_1 ≥ 2"처럼 변수 하나씩 기준값과 비교하기 때문에 스케일에 영향받지 않지만, 신경망은 모든 변수를 한꺼번에 곱하고 더하기 때문에 값이 큰 변수(예: BILL_AMT1, 수만~수십만 단위)가 값이 작은 변수(예: PAY_1, -2~8 범위)를 압도해버릴 수 있다. 이 차이를 5절과 7.3절에서 직접 확인한다.

4. 용어와 수식

퍼셉트론(뉴런): 입력 $x_1, \ldots, x_n$에 각각 가중치 $w_1, \ldots, w_n$를 곱해 더하고 편향 $b$를 더한 값(가중합) $z = \sum_i w_i x_i + b$를, 활성화함수 $f$에 통과시켜 출력 $a = f(z)$를 만드는 계산 단위.

활성화함수(Activation Function): 가중합을 비선형으로 바꿔주는 함수. 은닉층에서는 주로 ReLU($f(z) = \max(0, z)$, 0보다 작으면 0, 크면 그대로 통과)를 쓰고, 이 절처럼 이진분류의 출력층에서는 시그모이드($\sigma(z) = \frac{1}{1+e^{-z}}$, 0~1 사이 확률로 변환)를 쓴다. 활성화함수가 없으면(즉 선형함수만 쌓으면) 층을 아무리 쌓아도 결국 하나의 선형모델과 같아져, "층을 쌓는" 의미가 사라진다.

다층 퍼셉트론(MLP, Multi-Layer Perceptron): 뉴런들을 여러 층(입력층 → 은닉층(들) → 출력층)으로 배치하고, 한 층의 출력이 다음 층 전체의 입력이 되는(완전연결, fully-connected) 구조. "딥러닝"은 통상 은닉층이 여러 개(깊게) 쌓인 신경망을 뜻하며, MLP는 그중 가장 기본적인 형태다.

순전파(Forward Propagation): 입력에서 출력 방향으로 가중합과 활성화함수를 층마다 순서대로 계산해 최종 예측값을 얻는 과정.

손실함수(Loss Function): 예측이 정답과 얼마나 다른지 재는 함수. 이진분류에서는 이진 교차 엔트로피(Binary Cross-Entropy) $L = -[y\log(a) + (1-y)\log(1-a)]$를 쓴다($y$는 실제 레이블 0/1, $a$는 예측확률). $y=1$인데 $a$가 0에 가까우면(자신 있게 틀리면) $L$이 매우 커지고, $a$가 1에 가까우면(맞으면) $L$이 0에 가까워진다.

역전파(Backpropagation): 손실함수를 각 가중치로 미분한 값(그레이디언트)을, 출력층에서 입력층 방향으로 연쇄법칙(chain rule)을 이용해 효율적으로 계산하는 방법. 시그모이드 출력 + 교차 엔트로피 손실의 조합에서는 $\frac{\partial L}{\partial z} = a - y$로 깔끔하게 정리되는데(5절에서 직접 유도), 이 값에 이전 층의 출력을 곱하면 그 층 가중치의 그레이디언트가 된다.

경사하강법으로 가중치 갱신: 5부에서 배운 것과 완전히 같은 원리다. 그레이디언트가 가리키는 방향의 반대로, 학습률(learning rate)만큼 가중치를 이동시킨다: $w_{\text{새}} = w_{\text{기존}} - \text{학습률} \times \frac{\partial L}{\partial w}$.

에폭(Epoch): 학습 데이터 전체를 한 번 다 사용해 가중치를 갱신하는 한 번의 반복 단위. 신경망은 보통 수십~수백 에폭을 반복하며 손실을 점차 줄여나간다(4부의 GridSearchCV처럼 한 번에 끝나지 않는다).

5. 손으로 확인하는 작은 숫자 예제

가장 작은 신경망 — 입력 2개, 은닉 뉴런 1개, 출력 뉴런 1개 — 으로 순전파와 역전파를 한 단계씩 손으로 계산한다. (실제 신경망은 입력 29개·은닉 뉴런 48개를 쓰지만, 계산 원리는 이 작은 예제와 완전히 같다.)

설정: 표준화된 입력 $x_1=1.0$(예: PAY_1이 평균보다 1 표준편차 높음), $x_2=-1.0$(예: LIMIT_BAL이 평균보다 1 표준편차 낮음). 은닉 뉴런의 가중치 $w_1=0.5, w_2=-0.3$, 편향 $b_1=0.1$, 활성화함수는 시그모이드. 출력 뉴런의 가중치 $v=0.8$, 편향 $c=-0.2$, 활성화함수는 시그모이드. 실제 레이블 $y=1$(연체).

순전파:

$$z_1 = w_1 x_1 + w_2 x_2 + b_1 = 0.5(1.0) + (-0.3)(-1.0) + 0.1 = 0.9$$

$$a_1 = \sigma(0.9) = \frac{1}{1+e^{-0.9}} = 0.7109$$

$$z_2 = v \cdot a_1 + c = 0.8(0.7109) - 0.2 = 0.3688$$

$$a_2 = \sigma(0.3688) = 0.5912 \quad \text{(모델의 예측확률)}$$

손실: $L = -[1 \cdot \log(0.5912) + 0 \cdot \log(1-0.5912)] = -\log(0.5912) = 0.5257$

역전파 (출력층 가중치 $v, c$에 대한 그레이디언트만 계산 — 시그모이드+교차엔트로피의 성질로 $\frac{\partial L}{\partial z_2} = a_2 - y$):

$$\frac{\partial L}{\partial z_2} = a_2 - y = 0.5912 - 1 = -0.4088$$

$$\frac{\partial L}{\partial v} = \frac{\partial L}{\partial z_2} \cdot a_1 = -0.4088 \times 0.7109 = -0.2907, \qquad \frac{\partial L}{\partial c} = \frac{\partial L}{\partial z_2} \cdot 1 = -0.4088$$

가중치 갱신 (학습률 0.5): $v_{\text{새}} = 0.8 - 0.5(-0.2907) = 0.9453$, $c_{\text{새}} = -0.2 - 0.5(-0.4088) = 0.0044$

검산: 새 가중치로 다시 순전파하면 $z_2 = 0.9453(0.7109) + 0.0044 = 0.6763$, $a_2 = \sigma(0.6763) = 0.6630$. 실제 레이블이 1이었으므로 예측확률이 0.5912 → 0.6630으로 정답 쪽으로 이동했고, 손실도 0.5257 → 0.4110으로 줄어들었다. 이것이 경사하강법 한 걸음의 효과이며, 실제 학습은 이 과정을 모든 가중치에 대해, 수만 개의 데이터로, 수십 에폭 반복한다.

이 손 계산은 7.1절 코드에서 동일한 숫자로 재현해 검증한다.

6. 데이터 정의와 분석 설계

이 절은 2~4부와 완전히 동일한 데이터(UCI 신용카드 연체 데이터, 30,000행)와 완전히 동일한 학습(24,000)/테스트(6,000) 층화 분할(random_state=42)을 사용한다. 신경망 고유의 설계 원칙 두 가지를 추가한다.

모든 수치형 변수를 표준화한다: Pipeline 안의 ColumnTransformer가 학습 세트에서만 평균·표준편차를 추정하고 테스트 세트에는 그 값을 적용만 하는 원칙은 2부와 동일하지만, 신경망에서는 이 표준화가 "정확도를 살짝 높이는 선택"이 아니라 모델이 제대로 학습되기 위한 필수 조건에 가깝다(7.3절에서 확인).

하이퍼파라미터(은닉층 구조, 정규화 강도)는 학습 세트 내부 교차검증으로만 고른다: 4부에서 트리 깊이를 고를 때와 같은 원칙이다. 은닉층 뉴런 수, 정규화 강도(alpha)는 GridSearchCV(cv=3)로 탐색하고, 테스트 세트는 최종 확인에만 쓴다.

7. 단계별 실습 코드와 설명

실행 환경: 2~4부와 동일(Python 3.11+/pandas 3.0.2/numpy 2.4.4/scikit-learn 1.8.0/matplotlib 3.10.9). 전체 실행 시간 약 35초.

7.1 손 계산 재현

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

x1, x2 = 1.0, -1.0
w1, w2, b1 = 0.5, -0.3, 0.1
v, c = 0.8, -0.2
y_true = 1

z1 = w1 * x1 + w2 * x2 + b1
a1 = sigmoid(z1)
z2 = v * a1 + c
a2 = sigmoid(z2)
loss = -(y_true * np.log(a2) + (1 - y_true) * np.log(1 - a2))

dz2 = a2 - y_true
dv = dz2 * a1
dc = dz2 * 1

lr = 0.5
v_new = v - lr * dv
c_new = c - lr * dc
z2_new = v_new * a1 + c_new
a2_new = sigmoid(z2_new)
loss_new = -(y_true * np.log(a2_new) + (1 - y_true) * np.log(1 - a2_new))

print("z1=", round(z1, 4), "a1=", round(a1, 4))
print("z2=", round(z2, 4), "a2(예측확률)=", round(a2, 4), "loss=", round(loss, 4))
print("dz2=", round(dz2, 4), "dv=", round(dv, 4), "dc=", round(dc, 4))
print("갱신 후 v=", round(v_new, 4), "c=", round(c_new, 4),
      "새 예측=", round(a2_new, 4), "새 loss=", round(loss_new, 4))

실제 실행 결과: $z_1=0.9$, $a_1=0.7109$, $z_2=0.3688$, 예측확률 $a_2=0.5912$, 손실 $=0.5257$. 갱신 후 $v=0.9453$, $c=0.0044$, 새 예측확률 $=0.6630$, 새 손실 $=0.4110$ — 5절의 손 계산과 정확히 일치한다.

df["MARRIAGE"] = df["MARRIAGE"].replace({0: 3})

X = df.drop(columns=["default"]); y = df["default"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=RANDOM_STATE
)

numeric_features = ["LIMIT_BAL", "AGE", "PAY_1", "PAY_2", "PAY_3", "PAY_4", "PAY_5", "PAY_6",
    "BILL_AMT1", "BILL_AMT2", "BILL_AMT3", "BILL_AMT4", "BILL_AMT5", "BILL_AMT6",
    "PAY_AMT1", "PAY_AMT2", "PAY_AMT3", "PAY_AMT4", "PAY_AMT5", "PAY_AMT6"]
categorical_features = ["SEX", "EDUCATION", "MARRIAGE"]

def make_preprocess():
    return ColumnTransformer([("num", StandardScaler(), numeric_features),
                               ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features)])

7.3 표준화의 효과 — 신경망은 트리와 달리 스케일에 민감하다

mlp_scaled = Pipeline([("preprocess", make_preprocess()),
                        ("model", MLPClassifier(hidden_layer_sizes=(32, 16), alpha=1e-3,
                                                 early_stopping=True, n_iter_no_change=10,
                                                 max_iter=300, random_state=RANDOM_STATE))])
mlp_scaled.fit(X_train, y_train)
auc_scaled = roc_auc_score(y_test, mlp_scaled.predict_proba(X_test)[:, 1])

mlp_noscale = Pipeline([
    ("preprocess", ColumnTransformer([
        ("num", "passthrough", numeric_features),
        ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features),
    ])),
    ("model", MLPClassifier(hidden_layer_sizes=(32, 16), alpha=1e-3,
                             early_stopping=True, n_iter_no_change=10,
                             max_iter=300, random_state=RANDOM_STATE)),
])
mlp_noscale.fit(X_train, y_train)
auc_noscale = roc_auc_score(y_test, mlp_noscale.predict_proba(X_test)[:, 1])

print("표준화 적용 AUC=", round(auc_scaled, 4), " / 표준화 미적용 AUC=", round(auc_noscale, 4))

실제 실행 결과: 표준화를 적용하면 테스트 AUC 0.7620인데, 정확히 같은 구조에서 표준화만 빼면 AUC가 0.6048로 급락한다(그림 10-2). BILL_AMT1처럼 수만 단위인 변수가 PAY_1처럼 한 자릿수인 변수를 가중합에서 압도해버려, 신경망이 작은 스케일의 신호를 거의 학습하지 못하기 때문이다. 결정트리·GBM은 표준화 없이도(4부에서 실제로 표준화를 적용하긴 했지만) 성능이 거의 변하지 않는다 — 트리는 변수 하나씩 기준값과 비교할 뿐, 여러 변수를 한꺼번에 곱하고 더하지 않기 때문이다.

7.4 은닉층 구조·정규화 강도 선택 (GridSearchCV, 학습 세트 내부 교차검증만 사용)

pipe = Pipeline([("preprocess", make_preprocess()),
                  ("model", MLPClassifier(early_stopping=True, n_iter_no_change=10,
                                           max_iter=300, random_state=RANDOM_STATE))])
param_grid = {
    "model__hidden_layer_sizes": [(8,), (32, 16)],
    "model__alpha": [1e-4, 1e-3, 1e-2],
}
gs = GridSearchCV(pipe, param_grid, scoring="roc_auc", cv=3, n_jobs=-1)
gs.fit(X_train, y_train)
print("최적 구조·alpha=", gs.best_params_, "교차검증 AUC=", round(gs.best_score_, 4))
for p, s in sorted(zip(gs.cv_results_["params"], gs.cv_results_["mean_test_score"]), key=lambda t: -t[1]):
    print("  ", p, round(s, 4))

best_mlp = gs.best_estimator_
mlp_test_proba = best_mlp.predict_proba(X_test)[:, 1]
mlp_test_pred = (mlp_test_proba >= 0.5).astype(int)
mlp_auc = roc_auc_score(y_test, mlp_test_proba)
mlp_f1 = f1_score(y_test, mlp_test_pred)
mlp_prec = precision_score(y_test, mlp_test_pred)
mlp_rec = recall_score(y_test, mlp_test_pred)
print("[최종 MLP] 테스트 AUC=", round(mlp_auc, 4), "F1=", round(mlp_f1, 4),
      "정밀도=", round(mlp_prec, 4), "재현율=", round(mlp_rec, 4),
      "반복횟수=", best_mlp.named_steps["model"].n_iter_)

실제 실행 결과: 6개 조합 중 은닉층 (32, 16), alpha=0.0001이 교차검증 AUC 0.7723으로 가장 높았다. 이 최종 모델의 테스트 AUC는 0.7619, F1 0.4833, 정밀도 0.6576, 재현율 0.3821이며, 조기종료(early stopping)에 의해 19번의 반복 만에 학습이 멈췄다(최대 300으로 설정했지만 검증 손실이 10회 연속 개선되지 않아 자동 종료).

7.5 과대적합 실측 — 정규화·조기종료 없이 에폭을 늘렸을 때

pre_fitted = make_preprocess().fit(X_train, y_train)
Xtr_t = pre_fitted.transform(X_train)
Xte_t = pre_fitted.transform(X_test)

overfit_model = MLPClassifier(hidden_layer_sizes=(128, 64), alpha=0.0, max_iter=1,
                               warm_start=True, random_state=RANDOM_STATE)
train_aucs, test_aucs = [], []
N_EPOCHS = 80
for _ in range(N_EPOCHS):
    overfit_model.fit(Xtr_t, y_train)
    train_aucs.append(roc_auc_score(y_train, overfit_model.predict_proba(Xtr_t)[:, 1]))
    test_aucs.append(roc_auc_score(y_test, overfit_model.predict_proba(Xte_t)[:, 1]))

best_epoch = int(np.argmax(test_aucs))
print("최고 테스트 AUC 시점: epoch", best_epoch + 1,
      "test_auc=", round(test_aucs[best_epoch], 4), "train_auc=", round(train_aucs[best_epoch], 4))
print("마지막 epoch", N_EPOCHS,
      "test_auc=", round(test_aucs[-1], 4), "train_auc=", round(train_aucs[-1], 4))

실제 실행 결과: warm_start=True로 한 에폭씩 수동으로 반복하며 매 에폭마다 학습·테스트 AUC를 기록했다(정규화 없음, alpha=0, 조기종료 없음, 은닉층을 (128, 64)로 크게 키움 — 일부러 과대적합이 잘 일어나는 조건을 만들었다). 테스트 AUC는 7번째 에폭에서 0.7727로 정점을 찍고, 그 이후로는 계속 하락해 80번째 에폭에는 0.7384까지 떨어진다. 반면 학습 AUC는 80번째 에폭까지 계속 올라가 0.8668에 도달한다(그림 10-3). 학습 데이터의 세부 패턴(잡음 포함)까지 점점 더 정확히 암기하면서, 새로운 데이터에 대한 일반화 능력은 오히려 나빠지는 전형적인 과대적합이다 — 4부에서 트리 깊이를 늘렸을 때 본 현상과 원리는 같고, 축이 "트리 깊이"에서 "학습 에폭"으로 바뀌었을 뿐이다.

7.6 4부 모델과 최종 비교

from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

tree_pipe = Pipeline([("preprocess", make_preprocess()),
                       ("model", DecisionTreeClassifier(max_depth=6, random_state=RANDOM_STATE))])
rf_pipe = Pipeline([("preprocess", make_preprocess()),
                     ("model", RandomForestClassifier(n_estimators=300, max_depth=8,
                                                        random_state=RANDOM_STATE, n_jobs=-1))])
gbm_pipe = Pipeline([("preprocess", make_preprocess()),
                      ("model", GradientBoostingClassifier(n_estimators=200, max_depth=2,
                                                             random_state=RANDOM_STATE))])
comparison_rows = []
for name, model in [("결정트리(depth=6)", tree_pipe), ("랜덤포레스트", rf_pipe), ("GBM", gbm_pipe)]:
    model.fit(X_train, y_train)
    proba = model.predict_proba(X_test)[:, 1]
    pred = (proba >= 0.5).astype(int)
    comparison_rows.append((name, roc_auc_score(y_test, proba), f1_score(y_test, pred),
                             precision_score(y_test, pred), recall_score(y_test, pred)))
comparison_rows.append(("MLP(32,16)", mlp_auc, mlp_f1, mlp_prec, mlp_rec))

for name, auc, f1, prec, rec in comparison_rows:

8. 결과 읽는 법과 업무상 의미

신경망이 이 데이터에서 가장 뛰어나지는 않지만, 경쟁력은 있다: AUC 기준으로는 GBM(0.7763)·랜덤포레스트(0.7744)가 MLP(0.7619)보다 근소하게 앞선다. 이는 신경망이 무조건 트리 계열보다 우수하다는 통념과 다르다 — 표(정형) 데이터, 특히 이 정도 규모(3만 행, 23피처)에서는 GBM·랜덤포레스트 같은 트리 앙상블이 신경망과 비슷하거나 더 나은 성능을 내는 경우가 많다는 것이 여러 실무·연구 사례에서 반복적으로 보고되는 사실이며, 이번 실험도 그 패턴과 일치한다. 신경망이 확실한 우위를 보이는 영역은 이미지·텍스트·음성처럼 데이터 자체에 공간적·순차적 구조가 있는 경우로, 이 절의 합성곱·순환 구조가 없는 기본 MLP로는 그 이점을 활용할 수 없다.

그런데 F1은 MLP가 가장 높다: AUC로는 3위인 MLP가 F1(0.4833)에서는 4개 모델 중 가장 높다. 4부에서 이미 확인했듯 AUC와 F1(특정 임계값)은 다른 것을 재는 지표이며, 이번에도 그 사실이 재확인된다 — "어떤 지표를 기준으로 모델을 고르는가"가 실무적으로 중요한 이유다. 재현율(0.3821)도 MLP가 가장 높아, 이 임계값(0.5)에서는 MLP가 연체 계좌를 상대적으로 더 많이 찾아낸다.

스케일링은 신경망에서 선택이 아니라 필수에 가깝다: 7.3절에서 확인했듯 표준화를 빼면 AUC가 0.76에서 0.60으로 떨어져 사실상 무작위 예측에 가까워진다. 신경망을 실무에 적용할 때 "전처리 파이프라인에 표준화가 빠지지 않았는지" 반드시 확인해야 하는 이유다.

뉴런·층을 늘린다고 무조건 좋아지지 않는다: 7.5절의 과대적합 실험은 정규화나 조기종료 없이 큰 신경망(128, 64 뉴런)을 오래 학습시키면 학습 성능은 계속 좋아지지만 테스트 성능은 초반(7번째 에폭)에 정점을 찍고 하락한다는 것을 보여준다. 신경망을 실무에 쓴다면 조기종료·정규화·교차검증 같은 장치 없이 "일단 오래 학습시키고 보자"는 접근은 위험하다.

10. 흔한 오해와 오류

  • 오해 1: "딥러닝은 항상 다른 모델보다 성능이 좋다." 이 절의 실험에서는 GBM·랜덤포레스트가 AUC 기준으로 MLP보다 근소하게 앞섰다. 표(정형) 데이터에서는 트리 앙상블이 신경망과 비슷하거나 더 나은 경우가 흔하다 — 신경망의 강점은 이미지·텍스트처럼 원본 데이터에 공간적·순차적 구조가 있을 때 두드러진다.
  • 오해 2: "은닉층과 뉴런을 늘릴수록 더 좋은 모델이 된다." 7.5절에서 정규화·조기종료 없이 큰 신경망을 오래 학습시켰더니 테스트 성능이 7번째 에폭 이후 오히려 나빠졌다. 모델 용량(뉴런 수)은 데이터 양과 정규화 강도에 맞춰 균형을 잡아야 한다.
  • 오류 1: "신경망도 트리처럼 스케일링 없이 써도 괜찮다." 7.3절에서 확인했듯 표준화를 빼면 AUC가 0.76→0.60으로 급락한다. 신경망 전처리 파이프라인에서 표준화(또는 정규화)는 사실상 필수 단계다.
  • 오류 2: "AUC가 가장 높은 모델이 모든 지표에서 1등이다." 이 절에서 AUC 1위는 GBM이었지만 F1·재현율 1위는 MLP였다. 4부에서 배운 대로 지표와 임계값에 따라 결론이 달라질 수 있으므로, 실무 목적에 맞는 지표를 먼저 정하고 그 기준으로 모델을 비교해야 한다.

11. 핵심 요약

다층 퍼셉트론(MLP)은 가중합과 활성화함수를 층층이 쌓아 입력을 비선형으로 변환하고, 경사하강법과 역전파로 가중치를 학습하는 신경망이다. 이 절에서 실제로 학습시킨 MLP(은닉층 32·16개 뉴런)는 테스트 AUC 0.7619로, 4부의 GBM(0.7763)·랜덤포레스트(0.7744)보다는 낮지만 F1(0.4833)은 오히려 가장 높았다 — 신경망이 표 데이터에서 트리 앙상블과 대등하게 경쟁할 수 있지만 확실한 우위를 보장하지는 않는다는 것을 확인했다. 신경망은 트리와 달리 입력 스케일에 매우 민감해(표준화 없이는 AUC가 0.76→0.60으로 급락) 전처리가 필수이며, 은닉층·에폭 수를 무분별하게 늘리면 학습 성능은 계속 좋아져도 테스트 성능은 초반에 정점을 찍고 하락하는 과대적합이 나타난다. 신경망의 "왜 이 예측이 나왔는가"라는 설명가능성 문제는 4부·9부의 트리 계열보다 더 어려운데, 이는 11부에서 이어서 다룬다.

개념 문제

  1. 시그모이드 함수를 활성화함수로 쓰지 않고 항등함수(입력을 그대로 출력)만 층마다 사용하면 어떤 문제가 생기는지, "은닉층을 쌓는 의미"와 연결해서 설명하라.
  2. 신경망이 트리 모델과 달리 입력 스케일에 민감한 이유를 가중합 계산 방식으로 설명하라.

계산 문제

  1. 5절의 손 계산 예제에서, 학습률을 0.5 대신 1.0으로 바꾸면 $v_{\text{새}}$, $c_{\text{새}}$는 얼마가 되는지 계산하라.
  2. 은닉 뉴런의 가중합이 $z_1 = -2.0$일 때 ReLU 활성화값과 시그모이드 활성화값을 각각 계산하고 차이를 설명하라.

실습 문제

  1. hidden_layer_sizes를 (64, 32, 16)으로 늘리고 alpha를 0.01로 높여 재학습한 뒤, 테스트 AUC가 본문의 (32, 16) 모델보다 나아지는지 확인하라.
  2. 7.5절의 과대적합 실험에서 alpha=0.01(정규화 적용)로 바꿔 다시 실행하고, 테스트 AUC가 에폭이 늘어나도 크게 하락하지 않는지(정규화가 과대적합을 완화하는지) 확인하라.

연습문제 해설(별도)

  1. 활성화함수가 항등함수라면, 여러 층을 통과해도 결국 "가중치 행렬들의 곱"이라는 하나의 선형 변환과 수학적으로 동일해진다. 즉 은닉층을 100개 쌓아도 표현할 수 있는 함수의 종류는 층이 1개일 때와 같아진다 — 비선형 활성화함수가 있어야만 "층을 쌓는 것"이 실제로 더 복잡한 함수를 표현할 수 있게 해준다.
  2. 신경망의 각 뉴런은 모든 입력 변수에 가중치를 곱해 한꺼번에 더한다($z = \sum w_i x_i$). 이때 어떤 변수의 값 자체가 크면(예: BILL_AMT1이 수만 단위) 그 항이 전체 합을 지배해버려, 값이 작은 변수(예: PAY_1)의 가중치를 아무리 키워도 그 변수의 영향이 상대적으로 묻힌다. 표준화로 모든 변수를 비슷한 크기(평균 0, 표준편차 1)로 맞추면 가중치 학습이 어느 한 변수에 치우치지 않고 공정하게 이루어진다. 결정트리는 변수 하나씩 "이 값 이상인가"로 비교할 뿐 여러 변수를 곱하고 더하지 않으므로 이 문제가 생기지 않는다.
  3. $v_{\text{새}} = 0.8 - 1.0 \times (-0.2907) = 1.0907$, $c_{\text{새}} = -0.2 - 1.0 \times (-0.4088) = 0.2088$. 학습률이 클수록 한 걸음에 더 많이 이동한다(5부에서 배운 학습률과 수렴 속도의 관계와 동일).
  4. ReLU$(-2.0) = \max(0, -2.0) = 0$. 시그모이드$(-2.0) = 1/(1+e^{2.0}) = 0.1192$. ReLU는 음수를 완전히 0으로 만들어버리는 반면 시그모이드는 작지만 0이 아닌 값을 남긴다 — 이 차이 때문에 ReLU를 쓰는 은닉층의 일부 뉴런은 특정 입력에 대해 "완전히 꺼진" 상태가 될 수 있다.
  5. (실습형) 더 큰 구조가 항상 더 나은 테스트 성능을 보장하지 않는다는 것이 이 절의 핵심 메시지이므로, 구조를 키워도 교차검증 AUC나 테스트 AUC가 크게 개선되지 않거나 오히려 나빠질 수 있다.
  6. (실습형) alpha(L2 정규화 강도)를 높이면 가중치가 지나치게 커지는 것을 억제해, 에폭이 늘어나도 학습 데이터를 "암기"하는 속도가 느려진다. 그 결과 테스트 AUC가 그림 10-3만큼 급격히 하락하지 않고 상대적으로 안정적으로 유지될 가능성이 높다.

인계 메모

  • 완료한 범위: 10부("딥러닝 — 다층 퍼셉트론으로 신용위험 예측") 전체를 12단계 구조로 신규 집필하고, 실행·시각 검증까지 완료.
  • 이번 범위의 데이터 정의: 2~4부와 완전히 동일한 UCI 신용카드 실제 데이터(30,000행), 완전히 동일한 학습(24,000)/테스트(6,000) 층화 분할. 새로운 데이터를 도입하지 않았다.
  • 환경 선택 근거: TensorFlow·PyTorch 대신 scikit-learn MLPClassifier를 사용해 2~9부와 동일한 실행 환경을 유지했다(본문 서두 정정 안내 참고). 트리·앙상블 비교 대상(결정트리 depth=6, 랜덤포레스트, GBM)의 하이퍼파라미터는 4부의 GridSearchCV 최적값(n_estimators=300/max_depth=8, n_estimators=200/max_depth=2)을 그대로 재사용해, 4부와 정확히 같은 조건에서 재현했다.
  • 사용 환경과 데이터: Python 3.11+/pandas 3.0.2/numpy 2.4.4/scikit-learn 1.8.0/matplotlib 3.10.9(2~9부와 동일, 신규 패키지 설치 없음). 전체 스크립트 실행 시간 약 35초.
  • 코드·이미지 검증 상태: 5개 코드 블록 전체를 추출해 독립 스크립트로 재실행한 결과, 손 계산 재현값(z1=0.9, a1=0.7109 등), 스케일링 비교(0.7620 vs 0.6048), GridSearchCV 최적값·교차검증 AUC(0.7723), 최종 MLP 테스트 지표(AUC 0.7619, F1 0.4833), 과대적합 실험(최고점 epoch 7 AUC 0.7727, 마지막 epoch AUC 0.7384), 4개 모델 최종 비교표가 모두 본문과 정확히 일치함을 확인했다. 그림 4종 모두 실제 생성·육안 확인 완료.
  • 남은 문제: (1) 합성곱·순환·어텐션 등 구조가 있는 딥러닝(이미지·텍스트·시계열 특화)은 이 절에서 다루지 않음 — 정형 표 데이터라는 이 교재의 범위에 맞지 않기 때문이며, 향후 심화 절 후보로 남김 (2) GridSearchCV 탐색 범위(은닉층 2종·alpha 3종)는 계산 시간을 고려해 좁게 설정했으며, 더 넓은 탐색은 연습문제 5로 유도 (3) 배치정규화(Batch Normalization), 드롭아웃(Dropout) 같은 최신 정규화 기법은 MLPClassifier가 지원하지 않아 다루지 못함 — L2 정규화(alpha)와 조기종료만으로 과대적합을 통제하는 방법을 대신 다뤘다.
