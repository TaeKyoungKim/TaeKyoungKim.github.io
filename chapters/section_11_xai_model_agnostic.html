11부. XAI 심화 — 모델에 무관한 설명 기법으로 신경망 들여다보기

이 절에서 원문 대비 달라진 점: 원본 PDF를 재확인한 결과 원문은 Chapter 01~07로만 구성되어 있으며, 설명가능 AI(XAI)를 별도로 다루는 장은 존재하지 않는다. 이 절은 8부·9부·10부와 마찬가지로 원문에 대응하는 장이 전혀 없는, 이 교재가 새로 설계해 채운 절이며, "금융 빅데이터 분석"이 다루기로 약속한 범위를 채우기 위한 것임을 명시한다. 9부와의 관계: 9부는 트리 모델(GBM) 전용 설명 기법인 SHAP(TreeExplainer)을 다뤘다. 그런데 10부에서 만든 신경망(MLP)에는 TreeExplainer를 쓸 수 없다 — 트리 구조가 없기 때문이다. 이 절은 어떤 모델에도 적용할 수 있는(model-agnostic) 설명 기법 세 가지(순열 중요도, 부분의존도, 국소 근사)를 소개하고, 이를 10부의 MLP와 9부의 GBM에 함께 적용해 "모델이 달라도 같은 결론이 나오는가"를 직접 확인한다. LIME 패키지에 대한 안내: 이 절의 국소 근사는 널리 알려진 LIME(Local Interpretable Model-agnostic Explanations) 기법과 원리가 같지만, 공식 lime 패키지가 아니라 이 교재가 직접 구현한 코드다(패키지가 최신 빌드 도구와 호환되지 않아 이 실행 환경에 설치할 수 없었다) — 원리를 그대로 구현했다는 점과 공식 패키지가 아니라는 점을 분명히 밝힌다.

1. 금융 상황과 해결할 질문

10부에서 만든 신경망은 GBM만큼은 아니지만 경쟁력 있는 성능(AUC 0.7619)을 보였다. 그런데 신용위험 관리팀 회의에서 "이 신경망이 왜 이 고객을 고위험으로 분류했는지" 물었을 때, GBM처럼 feature_importances_나 SHAP을 바로 쓸 수 없다는 것을 알게 되었다 — 신경망에는 "트리 분기"라는 구조 자체가 없기 때문이다. 그렇다고 "신경망은 원래 설명할 수 없는 블랙박스"라고 포기할 수는 없다. 규제 대응이나 고객 설명 의무는 모델 종류와 무관하게 요구되기 때문이다.

트리 구조에 의존하지 않고, 어떤 모델에도 적용할 수 있는 설명 방법이 있는가? 그 방법으로 신경망을 설명한 결과가 9부에서 GBM을 SHAP으로 설명한 결과와 같은 결론을 가리키는가, 아니면 모델마다 다른 이야기를 하는가?

2. 학습목표와 선수지식

이 절을 마치면 다음을 할 수 있어야 한다.

  1. 순열 중요도(Permutation Importance)의 계산 원리를 설명하고, 트리 전용 지표(feature_importances_, SHAP)와 어떻게 다른지 구분할 수 있다.
  2. 부분의존도(PDP)를 계산·해석하고, 서로 다른 모델이 같은 변수에 대해 다르게 반응할 수 있음을 확인할 수 있다.
  3. 개별 예측에 대한 국소 근사(로컬 서러게이트) 설명을 직접 구현하고, 그 한계(국소 적합도)를 함께 보고할 수 있다.
  4. 여러 모델·여러 설명 기법에 걸쳐 같은 신호(변수)가 반복해서 나타나는지 확인해, 설명의 신뢰도를 스스로 판단할 수 있다.

선수지식: 9부의 SHAP·전역/개별 설명 개념, 10부의 MLP. 이 절의 세 기법은 모두 "모델 내부를 열어보지 않고, 입력을 바꿔가며 출력이 어떻게 반응하는지 관찰한다"는 공통 원리를 공유한다 — 이 직관만 있으면 새로 배울 수학은 많지 않다.

3. 직관적 설명

9부의 SHAP은 "이 나무가 어느 가지로 갈라졌는가"라는 트리 내부 구조를 직접 들여다보고 기여도를 계산했다. 이 절의 방법들은 정반대 전략을 쓴다 — 모델 내부를 전혀 보지 않고, 입력을 살짝 바꿔가며 출력이 얼마나 바뀌는지만 관찰한다. 마치 블랙박스로 만든 자판기를 이해하려고 회로를 뜯어보는 대신, 버튼을 하나씩 눌러보며 "이 버튼을 누르면 음료가 바뀌는구나"를 실험으로 알아내는 것과 비슷하다.

순열 중요도는 "이 변수의 값을 무작위로 뒤섞으면(그 변수가 가진 진짜 정보를 파괴하면) 모델 성능이 얼마나 나빠지는가"를 잰다. 성능이 크게 나빠질수록 그 변수가 중요하다는 뜻이다. 부분의존도(PDP)는 "다른 모든 변수는 그대로 두고, 이 변수 하나만 이 값 저 값으로 바꿔보면 모델의 평균 예측이 어떻게 변하는가"를 곡선으로 그린다. 국소 근사는 "이 고객 한 명 주변에서만" 모델이 어떻게 반응하는지 관찰해, 그 좁은 범위 안에서는 이해하기 쉬운 간단한 모델(선형회귀)로 흉내 낸다 — 복잡한 모델 전체를 이해하긴 어려워도 "이 한 고객 근처에서는" 단순한 규칙으로도 충분히 비슷하게 설명할 수 있다는 아이디어다.

4. 용어와 수식

순열 중요도(Permutation Importance): 변수 $j$의 값을 테스트 세트 안에서 무작위로 섞은 뒤(다른 변수는 그대로 둔 채) 모델 성능(이 절에서는 AUC)이 얼마나 떨어지는지를 그 변수의 중요도로 삼는다. 여러 번(이 절은 10회) 반복해 평균을 낸다 — 한 번의 우연한 섞임에 좌우되지 않기 위해서다.

부분의존도(Partial Dependence, PD): 변수 $x_j$를 특정 값 $v$로 고정하고 나머지 변수는 실제 데이터 그대로 둔 채, 데이터 전체에 대한 모델 예측의 평균을 구하는 것. $\text{PD}j(v) = \frac{1}{n}\sum{i=1}^n f(x_j=v, x_{-i,j})$($x_{-i,j}$는 $i$번째 데이터의 $j$를 제외한 나머지 변수들). $v$를 격자 형태로 여러 값 바꿔가며 계산하면 하나의 곡선이 된다.

국소 근사(Local Surrogate): 관심 있는 데이터 포인트 하나 주변에 무작위로 흔든(perturbation) 가상의 데이터를 여러 개 만들고, 원래 모델이 그 가상 데이터들에 대해 내놓는 예측을 "정답"으로 삼아, 해석하기 쉬운 간단한 모델(이 절에서는 릿지 회귀)을 그 점 근처에서만 새로 학습시키는 방법. 이때 원래 데이터 포인트에 가까운 가상 데이터에 더 큰 가중치를 준다(거리가 멀수록 그 지역 설명과 관련이 없으므로). 잘 알려진 LIME(Local Interpretable Model-agnostic Explanations)이 이 원리를 사용하며, 이 절의 구현도 같은 원리를 따른다.

로짓(logit) 변환: $\text{logit}(p) = \log\frac{p}{1-p}$. 확률 $p$가 0이나 1에 가까울(포화될) 때는 국소적으로 거의 평평해져 작은 입력 변화가 확률에 거의 반영되지 않는다. 로짓으로 변환하면 이 포화 구간에서도 국소 기울기를 더 안정적으로 추정할 수 있어, 이 절의 국소 근사는 확률이 아니라 로짓을 근사 대상으로 삼는다.

국소 결정계수($R^2$): 국소 근사 모델이 그 주변 가상 데이터들의 예측을 얼마나 잘 설명하는지 나타내는 값(1에 가까울수록 잘 맞음). 국소 근사는 "그 지점 근처에서만" 유효한 설명이므로, $R^2$가 낮으면 그 설명을 신뢰하기 어렵다는 신호로 함께 보고해야 한다.

5. 손으로 확인하는 작은 숫자 예제

가상의 계좌 5개와 모델의 예측확률이 다음과 같다고 하자(값은 설명용으로 단순화한 것이며 실제 데이터가 아니다).

계좌 PAY_1(원래 값) 예측확률
A 2 0.70
B 2 0.68
C -1 0.15
D -1 0.14
E 0 0.30

순열 중요도(손 계산): 이 5개로 계산한 AUC가 (실제 레이블과 비교해) 0.90이라고 하자. PAY_1 값을 무작위로 뒤섞어(A↔D, B↔C처럼) 다시 AUC를 계산했더니 0.55로 떨어졌다면, PAY_1의 순열 중요도는 $0.90 - 0.55 = 0.35$다. 값이 클수록 그 변수가 성능에 크게 기여하고 있었다는 뜻이다.

부분의존도(손 계산): PAY_1을 모든 계좌에서 강제로 $-2$로 고정하면 모델이 평균적으로 0.20을 예측하고, 강제로 $5$로 고정하면 평균 0.85를 예측한다고 하자. 이 두 점 $(-2, 0.20)$과 $(5, 0.85)$가 부분의존도 곡선의 두 점이 된다 — PAY_1이 커질수록 평균 예측이 올라가는 관계를 보여준다.

국소 근사(손 계산): 고객 A(PAY_1=2, 예측확률=0.70) 근처에서 PAY_1을 2.1, 1.9, 2.05, 1.95로 살짝 흔들며 모델 예측을 다시 구했더니 각각 0.715, 0.685, 0.708, 0.693이 나왔다고 하자. 이 4쌍의 (변화량, 예측 변화)로 기울기를 구하면 대략 $(0.715-0.685)/(2.1-1.9) = 0.15$ — "이 고객 근처에서는 PAY_1이 1 늘어날 때 예측확률이 약 0.15 늘어난다"는 국소적인 선형 관계를 얻는다. 실제 코드에서는 이 과정을 로짓 스케일로, 여러 변수에 대해 동시에, 수백 개의 가상 표본으로 수행한다(7.4절).

6. 데이터 정의와 분석 설계

이 절은 새 데이터를 만들지 않는다. 9부·10부와 완전히 동일한 UCI 신용카드 데이터, 동일한 학습/테스트 분할, 9부의 GBM과 10부의 MLP를 그대로 재사용한다. 모든 설명은 테스트 세트에서만 계산한다 — 3부 이후 지켜온 원칙과 동일하다. 국소 근사에 쓰는 가상 perturbation 데이터는 실제 고객 데이터가 아니라 계산을 위해 임시로 생성한 것이며, 저장하거나 실제 데이터인 것처럼 다루지 않는다.

7. 단계별 실습 코드와 설명

실행 환경: 2~10부와 동일(Python 3.11+/pandas 3.0.2/numpy 2.4.4/scikit-learn 1.8.0/matplotlib 3.10.9). 신규 패키지 설치 없이 scikit-learn의 sklearn.inspection 모듈(순열 중요도, 부분의존도)만 추가로 사용한다. 전체 실행 시간 약 20초.

7.1 9부 GBM · 10부 MLP 재현

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.neural_network import MLPClassifier
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import roc_auc_score

RANDOM_STATE = 42
raw = pd.read_csv("data/raw/UCI_Credit_Card.csv")
df = raw.drop(columns=["ID"]).rename(
    columns={"PAY_0": "PAY_1", "default.payment.next.month": "default"}
)
df["EDUCATION"] = df["EDUCATION"].replace({0: 4, 5: 4, 6: 4})
df["MARRIAGE"] = df["MARRIAGE"].replace({0: 3})

X = df.drop(columns=["default"]); y = df["default"]
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=RANDOM_STATE
)

numeric_features = ["LIMIT_BAL", "AGE", "PAY_1", "PAY_2", "PAY_3", "PAY_4", "PAY_5", "PAY_6",
    "BILL_AMT1", "BILL_AMT2", "BILL_AMT3", "BILL_AMT4", "BILL_AMT5", "BILL_AMT6",
    "PAY_AMT1", "PAY_AMT2", "PAY_AMT3", "PAY_AMT4", "PAY_AMT5", "PAY_AMT6"]
categorical_features = ["SEX", "EDUCATION", "MARRIAGE"]

def make_preprocess():
    return ColumnTransformer([("num", StandardScaler(), numeric_features),
                               ("cat", OneHotEncoder(handle_unknown="ignore"), categorical_features)])

mlp_pipe = Pipeline([("preprocess", make_preprocess()),
                      ("model", MLPClassifier(hidden_layer_sizes=(32, 16), alpha=1e-4,
                                               early_stopping=True, n_iter_no_change=10,
                                               max_iter=300, random_state=RANDOM_STATE))])
mlp_pipe.fit(X_train, y_train)
mlp_test_auc = roc_auc_score(y_test, mlp_pipe.predict_proba(X_test)[:, 1])

gbm_pipe = Pipeline([("preprocess", make_preprocess()),
                      ("model", GradientBoostingClassifier(n_estimators=200, max_depth=2,
                                                             random_state=RANDOM_STATE))])
gbm_pipe.fit(X_train, y_train)
gbm_test_auc = roc_auc_score(y_test, gbm_pipe.predict_proba(X_test)[:, 1])

print("MLP 테스트 AUC=", round(mlp_test_auc, 4), " GBM 테스트 AUC=", round(gbm_test_auc, 4))

실제 실행 결과: MLP 0.7619, GBM 0.7763 — 각각 10부·9부(4부 기준)와 정확히 일치한다(같은 모델을 재학습했으므로 당연한 결과이며, 이후 절의 설명 기법이 올바른 모델을 대상으로 하고 있는지 확인하는 절차다).

7.2 순열 중요도 (모델에 무관하게 적용)

from sklearn.inspection import permutation_importance

perm_mlp = permutation_importance(mlp_pipe, X_test, y_test, scoring="roc_auc",
                                   n_repeats=10, random_state=RANDOM_STATE, n_jobs=-1)
imp_mlp = pd.Series(perm_mlp.importances_mean, index=X_test.columns).sort_values(ascending=False)

perm_gbm = permutation_importance(gbm_pipe, X_test, y_test, scoring="roc_auc",
                                   n_repeats=10, random_state=RANDOM_STATE, n_jobs=-1)
imp_gbm = pd.Series(perm_gbm.importances_mean, index=X_test.columns).sort_values(ascending=False)

print("[MLP 순열 중요도 상위 5]")
print(imp_mlp.head(5).round(4))
print("[GBM 순열 중요도 상위 5]")
print(imp_gbm.head(5).round(4))
print("[상위 10개 겹침 개수]", len(set(imp_mlp.head(10).index) & set(imp_gbm.head(10).index)))

실제 실행 결과: 두 모델 모두 PAY_1을 압도적인 1위로 꼽는다(MLP 0.0946, GBM 0.0819 — 이 변수를 무작위로 섞으면 AUC가 각각 그만큼 떨어진다는 뜻). 2~3위는 LIMIT_BAL, BILL_AMT1로 두 모델이 동일하고, 상위 10개 중 6개가 겹친다(그림 11-1). 9부에서 GBM의 SHAP·feature_importances_가 공통으로 PAY_1을 1위로 꼽았던 것과도 일치한다 — 모델이 다르고 설명 기법이 달라도 "PAY_1이 가장 중요하다"는 결론은 반복해서 재현된다.

7.3 부분의존도(PDP) — PAY_1에 대한 두 모델의 반응 비교

from sklearn.inspection import partial_dependence

pdp_mlp = partial_dependence(mlp_pipe, X_test, ["PAY_1"], kind="average",
                              response_method="predict_proba")
pdp_gbm = partial_dependence(gbm_pipe, X_test, ["PAY_1"], kind="average",
                              response_method="predict_proba")
pay1_grid = pdp_mlp["grid_values"][0]
print("PAY_1 격자값:", list(pay1_grid))
print("MLP 평균예측확률:", list(pdp_mlp["average"][0].round(4)))
print("GBM 평균예측확률:", list(pdp_gbm["average"][0].round(4)))

실제 실행 결과: PAY_1이 $-2$에서 $8$로 커질수록 두 모델 모두 예측 연체확률이 올라간다는 큰 방향은 같지만, 구체적인 모양은 다르다(그림 11-2). MLP는 $-2$의 0.147부터 $8$의 0.970까지 완만하고 단조적으로(계속 증가하며) 올라간다. GBM은 $3$까지는 비슷하게 올라가다가(0.562), 오히려 $4$ 이후로는 소폭 하락해 0.488 부근에서 멈춘다 — PAY_1=6, 8처럼 실제 데이터에 드문 값에서는 트리가 충분한 근거를 학습하지 못해 평평해지거나 비직관적으로 움직일 수 있음을 보여준다. 반면 신경망은 연속함수 특성상 관측되지 않은 영역에서도 매끄럽게 외삽하는 경향이 있다 — 이는 어느 쪽이 "정답"이라기보다, 두 모델이 데이터가 희박한 영역에서 서로 다르게 행동한다는 것을 아는 것 자체가 중요하다는 교훈을 준다(8절에서 자세히).

7.4 국소 근사(로컬 서러게이트) — 개별 고객 설명

import numpy as np
from sklearn.linear_model import Ridge

def logit(p, eps=1e-6):
    p = np.clip(p, eps, 1 - eps)
    return np.log(p / (1 - p))

def local_surrogate(instance_row, model, X_ref, n_samples=800, sigma=0.6, seed=0):
    rng = np.random.RandomState(seed)
    base = instance_row.copy()
    stds = X_ref[numeric_features].std()
    samples = pd.DataFrame([base.values] * n_samples, columns=base.index)
    noise = rng.normal(0, 1, size=(n_samples, len(numeric_features))) * stds.values * sigma
    samples[numeric_features] = base[numeric_features].values + noise
    preds = model.predict_proba(samples)[:, 1]
    target = logit(preds)
    Z = noise / (stds.values * sigma)
    dist = np.sqrt((Z ** 2).sum(axis=1))
    weights = np.exp(-(dist ** 2) / 2)
    surrogate = Ridge(alpha=1.0)
    surrogate.fit(Z, target, sample_weight=weights)
    coefs = pd.Series(surrogate.coef_, index=numeric_features).sort_values(key=np.abs, ascending=False)
    r2 = surrogate.score(Z, target, sample_weight=weights)
    return coefs, surrogate.intercept_, r2

mlp_test_proba = mlp_pipe.predict_proba(X_test)[:, 1]
order = np.argsort(mlp_test_proba)
mid_high_idx = int(order[int(len(order) * 0.95)])
mid_low_idx = int(order[int(len(order) * 0.05)])

for idx, label in [(mid_high_idx, "고위험"), (mid_low_idx, "저위험")]:
    coefs, intercept, r2 = local_surrogate(X_test.iloc[idx], mlp_pipe, X_train, seed=RANDOM_STATE)
    print(f"[{label}] 예측확률={mlp_test_proba[idx]:.4f}, 로컬 절편={intercept:.4f}, 로컬 R^2={r2:.4f}")
    print(coefs.head(6).round(4))

실제 실행 결과: 상위 5% 위험 고객(예측확률 0.6742)의 경우 PAY_1(+0.0626)이 위험을 가장 크게 높이는 방향으로 기여했고, PAY_6(+0.0268)·PAY_AMT1(+0.0191)이 뒤를 이었으며 LIMIT_BAL(-0.0139)·PAY_AMT5(-0.0173)는 위험을 낮추는 방향이었다. 하위 5% 저위험 고객(예측확률 0.0464)은 PAY_1(+0.1910)의 영향이 훨씬 크게(부호는 같지만 계수 크기가 다르게) 나타났고, 나머지 변수들은 대부분 위험을 낮추는 방향이었다(그림 11-3). 두 설명 모두 국소 결정계수($R^2$)가 0.40~0.44 수준이었다 — 로짓 스케일로도 완벽하지는 않은, "이 근처에서는 대략 이런 경향"이라는 근사적 설명임을 함께 밝힌다(8절에서 이 한계를 자세히 논의).

8. 결과 읽는 법과 업무상 의미

세 가지 설명 기법과 9부의 SHAP이 공통적으로 가리키는 결론: 순열 중요도(MLP·GBM 모두), PDP, 국소 근사(고위험·저위험 모두), 그리고 9부의 SHAP·feature_importances_까지 — 이 절에서 확인한 4가지 이상의 서로 다른 방법이 전부 PAY_1(최근 상환상태)을 가장 중요한 신호로 지목한다. 서로 다른 모델 구조(트리 vs 신경망)와 서로 다른 설명 원리(내부 구조 분석 vs perturbation 기반)에서 같은 결론이 반복해서 나온다는 것은, 이 결론이 특정 알고리즘의 우연한 산물이 아니라 데이터 자체에 있는 강한 신호라는 확신을 높여준다. 하나의 모델, 하나의 설명 기법만 봤다면 이런 확신을 가질 수 없었을 것이다.

모델마다 세부적으로는 다르게 반응한다: PDP에서 확인했듯 PAY_1이 클 때(연체가 심할 때) MLP는 계속 위험도를 높게 예측하는 반면 GBM은 오히려 예측을 낮춘다. 두 모델 다 "정답"을 모르므로 어느 쪽이 맞는지는 이 데이터만으로 확정할 수 없지만, 실무에서는 이런 차이가 나는 구간(데이터가 희박한 극단값)에서 두 모델의 예측이 엇갈릴 수 있다는 것을 알고, 그 구간의 예측은 더 신중하게 다뤄야 한다는 실천적 함의를 준다.

국소 근사는 편리하지만 완벽하지 않다: 국소 결정계수가 0.40~0.44에 그쳤다는 것은, 이 절이 만든 간단한 선형 근사가 신경망의 실제 국소 동작을 절반 정도만 설명한다는 뜻이다. SHAP처럼 모델 내부 구조를 활용하는 기법(9부)은 일반적으로 이보다 더 정확한 설명을 주지만 트리에만 쓸 수 있다 — 설명 기법을 고를 때 "정확도 대 적용 범위"의 트레이드오프가 있다는 것이 이 절의 핵심 교훈이다.

10. 흔한 오해와 오류

  • 오해 1: "신경망은 원래 설명할 수 없는 블랙박스라 XAI를 적용할 수 없다." 이 절에서 확인했듯 순열 중요도·PDP·국소 근사는 모델 내부 구조와 무관하게 적용할 수 있어, 신경망에도 얼마든지 쓸 수 있다. "설명이 불가능한" 것이 아니라 "트리 전용 기법(SHAP TreeExplainer)을 못 쓸 뿐"이다.
  • 오해 2: "여러 설명 기법이 같은 변수를 1위로 꼽으면 그 설명은 100% 정확하다." 여러 기법이 일치한다는 것은 "신뢰도가 높다"는 신호일 뿐, 완벽함을 보장하지 않는다. 국소 근사의 $R^2$가 0.40~0.44에 그쳤듯, 각 기법 고유의 근사 오차는 항상 존재한다.
  • 오류 1: "부분의존도(PDP) 곡선이 이상하게 움직이면 모델이 잘못된 것이다." 7.3절에서 GBM의 PDP가 PAY_1이 클 때 하락한 것은 모델의 버그가 아니라 그 구간에 실제 데이터가 적어(희박해) 모델이 확신을 갖고 학습하지 못한 결과다. PDP가 이상하게 보이는 구간은 오히려 "그 영역의 예측을 조심해야 한다"는 유용한 신호로 읽어야 한다.
  • 오류 2: "국소 근사(LIME 방식)의 결과를 인용할 때 국소 적합도($R^2$)를 굳이 함께 보고할 필요는 없다." $R^2$ 없이 계수만 보고하면 독자는 그 설명이 얼마나 신뢰할 만한지 판단할 수 없다. 이 절처럼 근사 품질을 항상 함께 밝히는 것이 좋은 관행이다.

11. 핵심 요약

순열 중요도·부분의존도·국소 근사는 모델 내부 구조를 몰라도 입력과 출력의 관계만 관찰해 계산할 수 있는 모델-무관(model-agnostic) 설명 기법이다. 이 절에서 10부의 MLP와 9부의 GBM에 이 세 기법을 함께 적용한 결과, PAY_1(최근 상환상태)이 두 모델·모든 기법에 걸쳐 일관되게 가장 중요한 신호로 확인되어, 이 결론이 특정 모델의 우연이 아니라는 확신을 높였다. 동시에 부분의존도에서는 PAY_1이 클 때 두 모델이 서로 다르게(MLP는 계속 상승, GBM은 하락) 반응한다는 차이도 발견해, 데이터가 희박한 구간에서는 모델 간 예측이 엇갈릴 수 있다는 실무적 주의점을 확인했다. 국소 근사는 개별 고객 단위 설명을 어떤 모델에도 제공할 수 있다는 장점이 있지만, 국소 결정계수가 0.40~0.44에 그쳐 완벽한 설명이 아니라는 한계도 함께 보고해야 한다.

12. 연습문제

개념 문제

  1. 순열 중요도와 SHAP(9부)이 "중요도"를 계산하는 방식이 근본적으로 어떻게 다른지 설명하라.
  2. 국소 근사(로컬 서러게이트)에서 원래 데이터 포인트에 가까운 가상 표본에 더 큰 가중치를 주는 이유를 설명하라.

계산 문제

  1. 5절의 순열 중요도 손 계산에서, 뒤섞기 후 AUC가 0.55가 아니라 0.72였다면 순열 중요도는 얼마인가?
  2. 부분의존도 두 점이 $(x=0, \text{PD}=0.20)$과 $(x=10, \text{PD}=0.90)$일 때, 이 구간의 평균적인 기울기(민감도)를 계산하라.

실습 문제

  1. 7.2절의 순열 중요도를 GBM 대신 결정트리(depth=6, 4부 모델)에도 적용해, GBM·MLP와 상위 5개 변수가 얼마나 겹치는지 확인하라.
  2. 7.4절의 국소 근사를 n_samples=200으로 줄여 다시 계산하고, 계수와 국소 $R^2$가 n_samples=800일 때와 얼마나 달라지는지 비교해 표본 수가 설명의 안정성에 미치는 영향을 확인하라.

연습문제 해설(별도)

  1. SHAP은 게임이론(Shapley value)에 기반해, 모델 내부(이 교재에서는 트리 구조)를 직접 이용해 "이 피처가 없었다면 예측이 얼마나 달라졌을까"를 여러 피처 조합에 대해 정확하게(또는 트리 구조를 활용해 효율적으로 근사) 계산한다. 순열 중요도는 모델 내부를 전혀 보지 않고, 그 피처의 값을 실제로 뒤섞어 모델 성능이 얼마나 나빠지는지를 실험적으로 측정한다 — SHAP은 "설명"에, 순열 중요도는 "성능 기여도 실험"에 더 가깝다.
  2. 국소 근사의 목적은 "관심 있는 그 지점 근처에서" 원래 모델의 동작을 흉내 내는 것이다. 관심 지점에서 멀리 떨어진 가상 표본은 그 지점 근처의 국소적인 동작과 무관한 정보를 담고 있을 수 있으므로, 가까운 표본에 더 큰 가중치를 줘야 "그 지점 근처의" 설명으로서 의미가 있다. 모든 표본에 동일한 가중치를 주면 그 지점과 상관없는 전역적인 관계를 섞어서 학습하게 된다.
  3. $0.90 - 0.72 = 0.18$.
  4. $(0.90-0.20)/(10-0) = 0.07$ — $x$가 1 늘어날 때 부분의존도가 평균적으로 0.07 늘어난다는 뜻이다.
  5. (실습형) 결정트리는 단일 트리라 GBM·MLP보다 더 소수의 변수에 중요도가 집중되는 경향이 있을 수 있다 — 상위 5개 중 몇 개가 겹치는지 직접 확인하는 것이 이 문제의 목적이다.
  6. (실습형) 표본 수를 줄이면 가상 데이터의 무작위성에 따라 계수가 더 불안정해지고(같은 고객에 대해 실행할 때마다 결과가 조금씩 달라짐), 국소 $R^2$도 낮아질 가능성이 높다 — 국소 근사는 표본 수가 충분해야 안정적인 설명을 준다는 것을 확인하는 문제다.

  • 이번 범위의 데이터 정의: 9~10부와 완전히 동일한 UCI 신용카드 실제 데이터, 완전히 동일한 학습/테스트 분할. 국소 근사에 쓰인 perturbation 표본은 실제 데이터가 아닌, 설명 계산을 위해 그때그때 생성한 임시 가상 데이터이며 저장하지 않았다.
  • 환경·구현 관련 안내: 공식 lime 패키지는 최신 setuptools와의 호환성 문제로 이 환경에 설치되지 않아(AttributeError: install_layout), 같은 원리(perturbation + 거리가중 국소 선형회귀)를 이 절이 직접 구현했다 — 본문 서두와 4·7.4절에 이 사실을 명시했다. sklearn.inspection.permutation_importance, sklearn.inspection.partial_dependence는 scikit-learn 표준 기능으로 신규 설치 없이 사용했다.
  • 사용 환경과 데이터: Python 3.11+/pandas 3.0.2/numpy 2.4.4/scikit-learn 1.8.0/matplotlib 3.10.9(신규 패키지 설치 없음). 전체 스크립트 실행 시간 약 20초.
  • 코드·이미지 검증 상태: 4개 코드 블록 전체를 추출해 독립 스크립트로 재실행한 결과, 재현된 두 모델의 AUC(MLP 0.7619, GBM 0.7763), 순열 중요도 상위 5개·겹침 개수(6개), PDP 격자값·평균예측확률(MLP·GBM 각 10개 값), 국소 근사 계수·절편·$R^2$(고위험 0.4443, 저위험 0.4039)가 모두 본문과 정확히 일치함을 확인했다. 그림 3종 모두 실제 생성·육안 확인 완료.
  • 남은 문제: (1) 국소 근사의 perturbation 방식(가우시안 노이즈, sigma=0.6)은 이 절이 임의로 정한 하이퍼파라미터이며, 다른 sigma 값에서 결과가 얼마나 민감하게 바뀌는지는 연습문제 6으로만 다루고 본문에서 체계적으로 탐색하지 않음 (2) 범주형 변수(SEX, EDUCATION, MARRIAGE)는 국소 근사·PDP 계산에서 원래 값으로 고정하고 수치형 변수만 흔들었다 — 범주형 변수까지 포함한 완전한 국소 근사는 이 절의 범위를 넘어섬 (3) 공식 SHAP을 신경망에 적용하는 KernelExplainer(모델-무관 SHAP)는 계산 비용이 크고 9부에서 이미 TreeExplainer를 다뤘으므로 이 절에서는 다루지 않음 — 향후 심화 절 후보로 남김.
