주요 YAML 매니페스트 필드 레퍼런스

Deployment, Service, StatefulSet, PVC, HPA 작성 시 필수 및 권장 필드 상세 가이드

1. RAG API Deployment 매니페스트 명세

apiVersion: apps/v1
kind: Deployment
metadata:
  name: rag-api
  namespace: rag-system
  labels:
    app: rag-api
spec:
  replicas: 2
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
  selector:
    matchLabels:
      app: rag-api
  template:
    metadata:
      labels:
        app: rag-api
    spec:
      containers:
      - name: api
        image: rag-api:v1
        imagePullPolicy: IfNotPresent
        ports:
        - containerPort: 8000
        resources:
          requests:
            cpu: "250m"
            memory: "512Mi"
          limits:
            cpu: "1000m"
            memory: "1Gi"
        envFrom:
        - configMapRef:
            name: rag-config
        - secretRef:
            name: rag-secret
        livenessProbe:
          httpGet:
            path: /health
            port: 8000
          initialDelaySeconds: 15
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /ready
            port: 8000
          initialDelaySeconds: 5
          periodSeconds: 5

실전 트러블슈팅 가이드 (Top 6 장애 대응)

K8s 실습 및 프로덕션 환경에서 가장 흔히 발생하는 파드 에러의 원인과 해결 절차

증상 / 에러주요 원인즉각 해결 조치
CrashLoopBackOff 애플리케이션 진입점 오류, 필수 환경변수(DB URL, API Key) 누락, 포트 충돌 kubectl logs <pod> --previous 로 비정상 종료 스택트레이스 확인 후 ConfigMap/Secret 주입값 교정
ImagePullBackOff 도커 이미지 이름/태그 오타, 로컬 클러스터에 이미지 미로드, 인증 실패 minikube image load <image> 또는 Kind load 재수행. imagePullPolicy: IfNotPresent 설정
Pending 노드 리소스(CPU/MEM) 부족, PVC 볼륨 바인딩 실패(StorageClass 부재) kubectl describe pod로 Events 확인. requests 값 하향 조정 또는 PVC/PV 스토리지 클래스 확인
OOMKilled 임베딩 모델 로드 시 파드 메모리가 limits.memory 초과 메모리 한도(limits) 상향(예: 512Mi → 1.5Gi) 및 대용량 배치 청크 크기 축소
Service 502 / 503 파드의 readinessProbe 실패로 엔드포인트(Endpoints)에 등록되지 않음 kubectl get endpoints <svc> 확인. 파드가 완전히 부팅될 때까지 initialDelaySeconds 연장
DNS Lookup Fail 파드 간 통신 시 서비스 이름을 잘못 입력했거나 CoreDNS 장애 nslookup <service>.<namespace>.svc.cluster.local 로 클러스터 내부 FQDN 도메인 질의 검증

부록 D

클라우드 네이티브 RAG 핵심 용어 사전

쿠버네티스 인프라와 생성형 AI 엔지니어링의 융합 전문 용어 해설

  • StatefulSet: 파드마다 순차적인 인덱스와 고유한 볼륨(PVC)을 보장하는 컨트롤러로, 벡터DB·RDBMS처럼 영속 데이터가 필수인 시스템에 사용.
  • HNSW (Hierarchical Navigable Small World): 고차원 임베딩 벡터를 다층 그래프 구조로 인덱싱하여 빠른 근사 최근접 이웃(ANN) 검색을 수행하는 알고리즘.
  • Context Injection: 벡터 검색으로 추출한 참조 문서 조각들을 LLM의 시스템/유저 프롬프트에 동적으로 삽입하여 환각을 억제하는 기법.
  • Tool Calling (함수 호출): LLM이 질의를 분석한 뒤 사전에 정의된 JSON 스키마에 따라 적절한 도구의 이름과 인자를 반환하는 인터페이스.
  • HPA (Horizontal Pod Autoscaler): 실시간 부하(CPU/Memory) 지표를 수집하여 Deployment의 복제본(Replicas) 개수를 탄력적으로 조정하는 자동화 컨트롤러.
