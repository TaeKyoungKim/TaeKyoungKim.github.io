실습 개요 및 아키텍처

Hardhat 3 기반 로컬 이더리움 노드를 구동하고, 근태 기록(출근/퇴근/근무시간 누적) 및 시급 기반 급여를 지급하는 AttendancePayroll.sol 스마트컨트랙트를 작성한 뒤, Viem 단위 테스트와 React 프론트엔드 연동을 완성합니다.

1. 스마트컨트랙트: AttendancePayroll.sol 핵심 코드

// SPDX-License-Identifier: MIT pragma solidity ^0.8.28; contract AttendancePayroll { address public owner; uint256 public constant HOURLY_RATE = 0.01 ether; // 시간당 0.01 ETH struct Employee { bool isRegistered; uint256 lastCheckInTime; uint256 accumulatedSeconds; uint256 unpaidSalary; } mapping(address => Employee) public employees; event EmployeeRegistered(address indexed employee); event CheckedIn(address indexed employee, uint256 timestamp); event CheckedOut(address indexed employee, uint256 duration, uint256 unpaidSalary); event PayrollPaid(address indexed employee, uint256 amount); modifier onlyOwner() { require(msg.sender == owner, "Only owner can call this"); _; } constructor() payable { owner = msg.sender; } function registerEmployee(address _emp) external onlyOwner { require(!employees[_emp].isRegistered, "Already registered"); employees[_emp].isRegistered = true; emit EmployeeRegistered(_emp); } function checkIn() external { require(employees[msg.sender].isRegistered, "Not registered"); require(employees[msg.sender].lastCheckInTime == 0, "Already checked in"); employees[msg.sender].lastCheckInTime = block.timestamp; emit CheckedIn(msg.sender, block.timestamp); } function checkOut() external { require(employees[msg.sender].lastCheckInTime > 0, "Must check in first"); uint256 duration = block.timestamp - employees[msg.sender].lastCheckInTime; employees[msg.sender].accumulatedSeconds += duration; employees[msg.sender].lastCheckInTime = 0; uint256 wage = (duration * HOURLY_RATE) / 3600; employees[msg.sender].unpaidSalary += wage; emit CheckedOut(msg.sender, duration, employees[msg.sender].unpaidSalary); } function payoutSalary(address payable _emp) external onlyOwner { uint256 amount = employees[_emp].unpaidSalary; require(amount > 0, "No unpaid salary"); require(address(this).balance >= amount, "Insufficient contract balance"); employees[_emp].unpaidSalary = 0; _emp.transfer(amount); emit PayrollPaid(_emp, amount); } }

2. 로컬 실행 및 프론트엔드 연동 4단계

  1. 로컬 노드 가동: npx hardhat node 실행하여 로컬 체인 ID 31337 생성 및 20개 테스트 계정 확보
  2. 컨트랙트 배포: npx hardhat ignition deploy ./ignition/modules/AttendancePayroll.ts --network localhost
  3. 테스트 자동화: npx hardhat test 로 직원 등록, 출근, 시간 경과(time.increase), 퇴근, 급여 지급 검증
  4. React + Viem 연동: MetaMask에서 Localhost 8545 네트워크 추가 후 컨트랙트 주소/ABI 바인딩

AI Agent가 사람 대신 블록체인을 감시하거나 거래를 보조할 때, 환각(Hallucination)에 의한 무단 출금이나 자산 손실을 방지하기 위해 3단계 승인 파이프라인(사전 시뮬레이션 → 금액/화이트리스트 가드 → 최종 사용자 서명)을 설계합니다.
